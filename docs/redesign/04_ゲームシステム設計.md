## はじめに：この設計で特に重要な考え方

### 5つの柱

1. **約束は「物」として残る。** トトが「はい」と言うたびに、その約束は相手の手元に残る。忘れても消えない。期限が来れば、相手が取り立てに来る。
2. **前半は「トトが真ん中の星」、後半は「人と人の網」。** 前半の約束は、すべてトトと誰か一人を結ぶ線になる（星の形）。全部がトトを通るので、トトが嘘をつけば何でも回る。そのかわり、トトが倒れれば全部が倒れる。後半の目標は、人と人を**直接**つなぐ取引の網を作ること。トトが嘘をつかなくても立っていられる形にする。
3. **相手は言葉より先に、体で答える。** 相手の本音は台詞ではなく、視線・手・姿勢・沈黙に先に出る（「しぐさ」）。プレイヤーは、何を差し出したとき、何に触れたときに相手が動いたかを見て、自分で読む。
4. **誰が何を知っているかが、世界を動かす。** 嘘は、乱数ではなく**人と人が出会ったとき**にばれる。城の中では、人物がそれぞれの予定で動き、勝手に出会い、勝手に話す。嘘を守るには、誰と誰を会わせないかを考えることになる。笑劇（ドタバタ）がそのまま仕組みになる。
5. **失敗は、次の場面になる。** 断られる、怒らせる、嘘がばれる。どれもゲームを止めない。相手が自分で動き出し、新しい問題として返ってくる。

### 既存の試作品（`digital_v1`）から変えること

| `digital_v1` | 本設計 |
|---|---|
| 王の言葉 × 根拠カード → 決まった結果（対応表） | 相手の**関心と恐れ**に照らして反応が決まる。同じ品でも、相手によって、場面によって反応が違う |
| 6つの条件枠を埋める提案フォーム | 卓に「品・約束・知っていること」を**差し出す**。相手も自分から要求し、対案を出してくる |
| 「王の我慢」という数値の資源 | 時間（1日に会える場面の数）と、相手の**姿勢**（4段階、体の向きで見せる） |
| 交渉は王との1回だけ | 前半は城の一週間で多くの1対1、後半は多人数。交渉の形そのものが変わる |
| 嘘や約束の仕組みがない | 約束と嘘が物として残り、期限と「知っている人」を持つ。**本作の中心の仕組み** |
| 情報は手帳のカードで、根拠として出すもの | 情報は「読みの手がかり」「渡せば価値になるもの」「漏れれば危ないもの」の3つの顔を持つ |

## 1. ゲームの基本コンセプト

### 1.1 ひとことで
> **約束を配って回すゲームから、約束を結び直すゲームへ。**

前半、プレイヤーは城の「何でも屋」として、次々に来る頼みごとに「はい」と言って捌いていく。それは気持ちよく、効率がいい。だが、手元の帳面には約束が溜まり、約束どうしがきしみ始める。
後半、その約束が一度に取り立てに来る。プレイヤーは、一人ひとりが本当に恐れているものを見極め、人と人を直接つなぐ取引を組んで、峠の卓で和平をまとめる。

### 1.2 プレイヤーが感じてほしいこと

| 時期 | 感じてほしいこと |
|---|---|
| 前半の始め | 「はいって言えば、みんな喜ぶ。簡単だ」 |
| 前半の中ごろ | 「この約束とあの約束、両方は守れないぞ……あの二人を会わせちゃいけない」 |
| 前半の終わり（ミッドポイント） | 「全部うまくいった！」 |
| 後半の始め（請求の日） | 「全部、自分が蒔いた種だ」 |
| 後半の中ごろ（カヤ村） | 「正直に言うのは怖い。でも、言ったら相手が一緒に考えてくれた」 |
| 後半の終わり（峠の卓） | 「この人がこれを怖がっているなら、あの人のあれと交換できる。自分で組んだ」 |

### 1.3 交渉の学びはどこに埋まっているか
理論の名前は、ゲーム中には出さない【推奨】。プレイヤーは次のことを、名前を知らずに体で覚える。

| 体験 | 対応する交渉の考え方（プレイヤーには示さない） |
|---|---|
| 「魔王を倒したい」の裏に「村を救いたい」がある | 立場と利害 |
| 断るときに「その代わり」を添えると、関係が壊れない | 代替案の提示 |
| 自分から打ち明けた嘘と、ばれた嘘では、相手の反応が違う | 信頼の修復 |
| 峠で全員が「決裂すれば自分が一番困る」と分かっている | 交渉が決裂した場合の代替案（BATNA） |
| 二人の条件が互いに相手待ちなので、同時に開く | 同時履行、条件付き合意 |
| 皆の前では強気な人が、別室では本音を言う | 公の場と私の場、面子 |

振り返りの扱いは §10.3 と【未決 G-8】を参照。

## 2. ゲームの基本ループ

ループは2つの大きさで回ります。

### 2.1 大きなループ：一日（前半）

```
 朝：帳面を開く
   ├ 今日が期限の約束
   ├ 届いた頼みごと・呼び出し
   └ 城の中の人の予定（誰がどこにいるか、分かる範囲で）
        ↓
 昼：場面を選んで、交渉する（1日に3場面）【推奨】
   ├ 誰に会うか（会いに行く／呼ばれて行く）
   └ 会わなかった人は、自分の予定どおりに動く
        ↓
 夜：城の夜（自分のいないところで起きたこと）
   ├ 誰と誰が出会ったか → 嘘が漏れる／噂が広がる
   ├ 期限を過ぎた約束 → 相手が動く
   └ 母への手紙（その日の自分を振り返る）
        ↓
 次の朝へ
```

- **時間が前半の資源**。1日に会えるのは3場面だけ。全員に会うことはできない。
- 「はい」はその場で話が終わるので、**場面を節約できる**。正直な断りや代案は、もう一度話す必要が出たり、他の人に相談しに行ったりで、場面を多く使う。ここに「はい」の合理性がある。
- 会わなかった人も止まってはいない。ヴェラは視察に来るし、ドグマは決闘の相手を探しに来るし、ピコは取材に出る。

### 2.2 小さなループ：一つの交渉の場面

```
 相手が来る（多くは、相手の要求を持って）
   ↓
 様子を見る ── しぐさ、置かれた品、誰を連れているか
   ↓
 働きかける ── 探る／差し出す／求める／明かす／応じる
   ↓
 反応を受け取る ── しぐさ → 姿勢の変化 → 台詞（この順で出る）
   ↓
 相手が動く ── 対案、新しい要求、試す、黙る、立ち去る
   ↓
 （繰り返し）
   ↓
 終わる ── 合意（約束が生まれる）／持ち帰る（宿題が生まれる）／物別れ（相手が自分で動き出す）
```

- 1つの場面は、**働きかけ4〜6回程度**で終わる長さにする【推奨】。
- 相手の姿勢が「閉じる」まで下がるか、話の種が尽きると、相手は席を立つ。

### 2.3 大きなループ：後半

後半は「一日3場面」ではなく、**期限に向かって進む区切り**で回る。

| 区切り | 物語 | ループの形 |
|---|---|---|
| 請求の日 | ⑩ | 溜まった約束が、一つずつ取り立てに来る。プレイヤーは各場面で、撤回する／打ち明ける／取り繕う、を選ぶ |
| カヤ村 | ⑪〜⑫ | リーナとの1対1。前半と同じ形の交渉だが、トトの手元には品も地位もない |
| 夜明け前 | ⑬ | 誰を呼ぶか、何を実演するかを選ぶ。来てくれるかどうかは、前半の関係で決まる |
| 峠の卓 | ⑭ | 多人数の交渉。**公の卓**と**別室**を行き来する。夜明けまでの時間が資源 |

### 2.4 物語のビートとループの対応

| ビート | ゲームの区間 | 主な交渉 |
|---|---|---|
| ①〜③ | 導入。小さな勇者一行（1回） | 仕組みを覚える。「はい」で捌く気持ちよさ |
| ④〜⑥ | リーナの一行の到着 | **例A**（§8）。一行4人との交渉 |
| ⑦〜⑧ | 城の一週間 | 一日ループ。各部署、ヴェラ、ドグマ、ガルザ、老商人 |
| ⑨ | 角折りの儀、帳簿室 | 交渉なし（偽りの勝利と反転を見せる）。リーナへの手紙の選択 |
| ⑩ | 請求の日 | 約束の清算 |
| ⑪〜⑫ | カヤ村 | リーナとの正直な交渉 |
| ⑬ | 夜明け前 | 仲間集め、実演 |
| ⑭ | 峠の卓 | **例B**（§9） |
| ⑮ | 結末 | 交渉なし |

## 3. 交渉の仕組み

### 3.1 案の比較：交渉を何で表すか

| 案 | 内容 | 評価 |
|---|---|---|
| ア. 会話の選択肢 | 台詞の選択肢を選ぶ | ✕ 文章を読んで正解を選ぶ形になる。依頼で禁止 |
| イ. カードバトル | 交渉カードを出してゲージを動かす | ✕ v1 で失敗した。人ではなく数値と戦うことになる |
| **ウ. 卓と品**【推奨】 | 卓の上に、品・約束・知っていることを置いて、相手とやりとりする。相手も自分から品を置き、求め、押し返してくる | ◯ 何を差し出したかが一目で分かる。相手の反応を「品への反応」として見せられる。言葉が少なくて済む |

以下、**ウ**を前提にする。

### 3.2 卓の上に置けるもの（トトの手元）

| 種類 | 例 | 特徴 |
|---|---|---|
| **品** | 宝箱、古い角、偽の書類、城の食券、地図 | 実物。渡せば手元からなくなる。数が限られる（ヴェラの予算） |
| **約束** | 「決闘を手配する」「城で雇う」「報告書は好きに書いていい」 | トトがこれからすることを差し出す。**作るのはただ**。そのかわり、相手の手元に残り、期限が来る |
| **話の種**（知っていること） | 「カヤ村は税で潰れかけている」「コックは人手が欲しい」「ガルザは引退したい」 | 相手に**明かす**ことも、相手について**探る**ときの手がかりにすることもできる。本当のことも、作り話も置ける |
| **人** | 「罠課の職人を連れてくる」「リーナに話してもらう」 | 第三者を場に呼ぶ。後半で重要になる |

**前半と後半で手元が変わる**：前半のトトは城の品（宝箱、予算、職員の立場）を持っている。⑩で課を外されると品はなくなり、**後半の手元は話の種と人（関係）だけ**になる。

### 3.3 プレイヤーの行動

行動は6つだけ【推奨】。後半に2つ増える。

| 行動 | 何をするか | 何が起きるか |
|---|---|---|
| **探る** | 相手の品、相手の連れ、話の種のどれかを指して「これは？」と聞く | 相手が答える。答えより先に、しぐさが出る。何に触れると相手が動くかが分かる |
| **差し出す** | 品・約束・話の種を相手の前に置く | 相手が受け取るか、押し返すか、迷うか。受け取れば姿勢が前に出る |
| **求める** | 相手の品を指して、こちらに引き寄せる（要求する） | 相手が譲るか、代わりのものを求めるか、怒るか |
| **明かす** | 話の種を、本当のこととして相手に伝える（作り話を伝えれば嘘になる） | 相手の知っていることが増える。相手も何かを明かし返すことがある。だが、相手がそれを他の人に話すかもしれない |
| **応じる** | 相手の要求に答える：**はい／いいえ／その代わり／持ち帰る** | §3.4 |
| **席を立つ** | 交渉を終える | 合意がなければ物別れ。相手は自分で動き出す |
| 後半：**つなぐ** | 二人の約束を「〜なら」で結ぶ（例：「ハーゲンが支持するなら、王は打ち明ける」） | §3.7 |
| 後半：**別室へ** | 公の卓を離れ、一人とだけ話す | §3.7 |

**選択肢の文を読んで選ぶのではない**。プレイヤーが選ぶのは「何を」「誰に」「どうするか」で、台詞はその結果として出てくる。

### 3.4 相手の要求への応じ方

前半の交渉の多くは、**相手が要求を持ってくる**ところから始まる。応じ方は4つ。

| 応じ方 | その場で | 後で | 使いどころ |
|---|---|---|---|
| **はい** | 相手は満足し、すぐに話が終わる。場面を節約できる | 約束が相手の手元に残る。守れなければ取り立てに来る | 相手の本当の望みが分からないとき、時間がないとき。**前半ではいちばん効く** |
| **いいえ** | 相手の姿勢が下がる。相手によっては怒る | 約束は残らない。相手によっては一目置かれる（ドグマ） | 守れない約束をしたくないとき |
| **その代わり** | 要求そのものではなく、**要求の裏にある望み**に応える品や約束を差し出す。望みに届けば、約束より深く満足する。外れると、相手は「そうじゃない」と押し返す | 相手の記憶に「この小鬼は、自分のことを分かっている」が残る | 相手の本当の望みが見えているとき。読みが要る |
| **持ち帰る** | 「確かめてきます」。相手は待つ | **宿題**が生まれる（期限つき）。別の人に相談しに行ける | 情報が足りないとき。時間を使うが、嘘をつかずに済む |

**「その代わり」がクイズにならないための工夫**【推奨】
- 一つの望みに応えられる品や約束は、**いつも複数ある**。例：リーナの「自分の力で何かを変えたい」には、罠課の本気の試練、村の代表として王に会う役目、ドグマとの本物の手合わせ、などが応える。
- 応え方には**深さ**がある。望みの一部にだけ応える案でも、相手は「半分だけ」受け取る（しぐさで分かる）。
- 相手は押し返すとき、**何が足りないかを、しぐさで見せる**。外れても次の手がかりになる。
- 相手のほうから対案を出してくることもある。

### 3.5 相手の反応の表し方

反応は、**しぐさ → 姿勢 → 台詞**の順に出る【推奨】。プレイヤーは、台詞を読む前に体の動きで察することができる。

**しぐさ**（その瞬間の、小さな体の動き）
- 一人ひとりに固有のしぐさがある。例：リーナは村の話になるとお守りを握る。ボルドは得になる話で指を折って数える。ガルザは本音に近づくと盆栽の枝をいじる。ドグマは怒りを溜めると斧の柄を握り直す。
- しぐさは、**相手の関心や恐れのどれに触れたか**を表す（§4.1）。
- 同じしぐさが繰り返されれば、プレイヤーはその意味を自分で覚えていく。

**姿勢**（その場面の中での、相手の構え）。4段階。数字では見せず、体の向き・距離・腕・目線で見せる。

| 姿勢 | 様子（例） | 意味 |
|---|---|---|
| 閉じる | 背を向ける、腕を組む、席を立ちかける | これ以上は話さない。次に悪化すると席を立つ |
| 構える | 椅子に深く座る、品を手元に引き寄せる | 警戒している。表向きの要求しか言わない |
| 聞く | こちらを向く、品から手を離す | 話を聞いている。探れば本音の一部が出る |
| 乗り出す | 身を乗り出す、自分から品を差し出す | 合意が近い。相手も譲る用意がある |

**台詞**：短い。台詞は気持ちを伝えるもので、ルールの説明はしない。

**相手の手番**：相手も働きかけてくる。
- 要求する、対案を出す、品を押し返す。
- **試す**（ボルド「前の担当は宝箱を三つ出したぞ」——本当かどうかは、しぐさで読む）。
- 黙る（ガルザ）、脅す（ドグマ）、話をそらす（エドモンド）、第三者を呼ぶ（ヴェラ）。

### 3.6 交渉が進んでいるかどうかの分かり方

| 状態 | プレイヤーに見えるもの |
|---|---|
| 前進 | 姿勢が前に出る。相手が自分から品を置く。卓の上の品が、相手とトトのあいだで行き来し始める |
| 停滞 | 姿勢が変わらない。相手が同じ要求を繰り返す。同じしぐさが続く |
| 悪化 | 姿勢が下がる。相手が品を手元に引き寄せる。連れが口を挟んでくる |
| 合意 | 相手が約束を受け取る（または、トトに約束をくれる）。握手、うなずきなど人物ごとの合意のしぐさ |

### 3.7 後半で増えるもの：公の卓、別室、つなぐ

後半（峠の卓）は多人数の交渉になり、3つの仕組みが加わる。

**公の卓と別室**
- **公の卓**では、全員が全員の言葉を聞いている。人は面子があるので、**表向きの立場**を崩さない。公の卓で一度言ったことは、引っ込めにくい。
- **別室**では、一人とだけ話せる。本音と恐れが出てくる。ただし、別室で決めたことは、公の卓で認められるまで成り立たない。
- 別室に行けるのは、夜明けまでに**限られた回数**だけ（§9）。

**つなぐ（条件付きの約束）**
- 前半の約束は「トト ⇔ 誰か」の線だった。後半は「誰か ⇔ 誰か」を結ぶ。
- 例：「辺境の諸侯が王を支持するなら、王は30年の真実を打ち明ける」。
- つないだ約束は、**両方の条件がそろったときにだけ**成り立つ。互いに相手待ちの約束は、公の卓で**同時に開く**ことで成り立たせる。

**星から網へ**
- 前半の帳面は、トトを真ん中にした星の形になっている。
- 後半の目標は、人と人が直接つながった網。最後にトトが抜けても、網が立っていられるかどうかが、結末を決める（§10）。

### 3.8 交渉を終える、持ち帰る、相談する

| 行動 | できるか | 結果 |
|---|---|---|
| 合意して終える | ◯ | 約束が生まれる |
| 持ち帰る | ◯ | 宿題が生まれる（期限つき）。期限を過ぎると、相手は待ちくたびれて自分で動き出す |
| 別の人に相談する | ◯ | 次の場面で別の人に会いに行く。情報、品、協力が得られることがある |
| 第三者を連れてくる | ◯ | 次の場面に誰かを同席させる。後半で重要（ハーゲンにはリーナの言葉が効く、など） |
| 物別れで終える | ◯ | 約束は生まれない。相手は自分の思うように動き出す（§7） |

## 4. 登場人物ごとの交渉ロジック

### 4.1 人物の作り方（共通）

人物を数値の集合にしないために、一人ひとりを次の要素で作る【推奨】。

| 要素 | 中身 | プレイヤーへの見せ方 |
|---|---|---|
| **関心**（3〜4つ） | その人が大事にしているもの。人によって重さが違う（重さは見せない） | 触れるとしぐさが出る |
| **恐れ**（1〜2つ） | 触れられると身構えるもの | 触れると姿勢が下がる。後半の鍵 |
| **一線** | どんな条件でも譲らないもの | 踏むと、その場で「閉じる」 |
| **癖** | 交渉の仕方の癖。過去の経験から来る | 相手の手番の動き方に表れる |
| **記憶** | トトとのあいだに起きた具体的な出来事 | 台詞やしぐさで触れられる（「前にも『火曜に』と言ったな」） |
| **関係** | 今の関係の種類（数値ではなく、状態） | 会ったときの第一声、迎え方 |

**関係は種類で持つ**【推奨】：警戒 → 取引相手 → 信頼、のほかに、**共犯**（互いの嘘を守り合う）、**負い目**（トトに借りがある、またはトトが借りがある）、**決裂**がある。どの種類になるかは、記憶の中身で決まる。たとえば、同じ「嘘がばれた」でも、自分から打ち明けたか、他人から聞いたかで、行き先が違う。

## 5. 情報収集と情報の価値

### 5.1 情報を「証拠カード」にしない

情報（話の種）には3つの使い道がある。正しいカードを正しい相手に出す、という使い方はしない。

| 使い道 | 例 |
|---|---|
| **読みの手がかり** | 「カヤ村は税で潰れかけている」と知っていると、リーナがお守りを握るしぐさの意味が分かる。知らなければ、ただのしぐさに見える |
| **渡せば価値になるもの** | ハーゲンが何より欲しいのは「30年の真実」。真実を明かすことそのものが、取引の品になる |
| **漏れれば危ないもの** | ピコに話した秘密は王へ流れる。ミントに話した弱みは、ミントの交渉材料になる |

### 5.2 情報の手に入れ方

| 入手の経路 | 例 | 確かさ |
|---|---|---|
| **しぐさを見る** | ボルドが「前の担当は宝箱を三つ出した」と言いながら、目をそらす | 読みにすぎない（外れることもある） |
| **探る** | コックに「人手は足りてる？」と聞く | 本人の言葉（ただし本人の見え方） |
| **人づてに聞く**（夜の噂） | 「ピコがまた手紙を出していたよ」 | 噂（確かめる必要がある） |
| **実物を見る** | 帳簿室の帳簿、老商人の荷車の量 | 確か |
| **他の交渉の結果** | コックと話すと、ボルドが料理上手だと分かる | 本人の言葉 |

**本音と言葉が違うことへの気づき方**：言葉としぐさが食い違う場面を用意する。例：ハーゲンは「谷を取り戻す」と言いながら、領民の話になると地図から目を離す。プレイヤーは、言葉ではなくしぐさのほうを信じてもいい。

### 5.3 誰が何を知っているか

- ゲームの中では、**一人ひとりが「知っていること」を持っている**。トトが誰かに何かを明かせば、その人の知っていることが増える。
- 人は会えば話す。夜の噂の時間に、出会った二人のあいだで、知っていることが移る（話す人と話さない人がいる。ピコは何でも話す。ガルザは何も話さない）。
- **トトの帳面に記されるのは、トトが「誰が何を知っているか」について知っていること**【推奨】。実際とは違うことがある。ピコが王に流していることは、帳面には載らない（伏線のしぐさで気づける）。

### 5.4 情報を明かす・隠す・誤解させる・正直に伝える

| 行動 | メリット | リスク |
|---|---|---|
| **正直に明かす** | 相手が明かし返してくれることがある。関係が深まる。後で嘘として爆発しない | 漏れる。こちらの弱みが相手の交渉材料になる。その場で相手が怒ることがある |
| **隠す**（何も言わない） | その場では何も起きない | 相手が他の人から知ったとき、「黙っていた」が記憶に残る（嘘ほどではない） |
| **誤解させる**（本当のことを、誤解されるように言う） | 嘘をついていないので、ばれても言い逃れの余地がある | 相手によっては嘘と同じに扱われる（リーナ、ハーゲン）。ミントには見抜かれる |
| **嘘をつく** | その場で一番効く | 嘘として帳面に残り、「知っている人」を持つ。期限や出会いで発覚する |

## 6. 嘘・約束・関係性の管理

### 6.1 約束の帳面

トトの帳面（①でトトが手にしているもの）が、この仕組みの中心【推奨】。帳面には、トトが交わしたすべての約束と嘘が載る。

**一つの約束が持つもの**

| 中身 | 例 |
|---|---|
| 誰に | ドグマ |
| 何を | 「勇者との本気の決闘を手配する」 |
| いつまでに | 「来週の火曜」（トトが言った期限、または相手が決めた期限） |
| 本当に守るつもりか | トトが「はい」と言った時点で、守れる見込みがあったか。なければ**嘘の約束** |
| 知っている人 | この約束が守れないことを知っている人（トト自身、ヴェラ、ガルザ……） |
| つながっている約束 | 矛盾する約束（「リーナを安全に城から出す」） |

**数値ではなく、中身で見せる**：嘘ポイントや信頼度のゲージは置かない。プレイヤーは帳面を開くと、「ドグマに何を約束したか」「それがいつ取り立てに来るか」「誰がそれを知っているか」を、具体的な中身として見る。

### 6.2 約束の一生

```
 生まれる（はい／その代わり／取引の合意）
   ↓
 相手の手元にある（相手は覚えている。会うたびに触れてくる）
   ↓
 期限が来る
   ├ 守る        → 相手の記憶に「守った」。関係が進む
   ├ 延ばす      → 「はい、来週こそ」。新しい期限。相手の記憶に「延ばされた」
   ├ 取り下げる  → 正直に「できません」と言い直す。その代わりを添えられる
   └ 放っておく  → 相手が取り立てに来る、または自分で動き出す
```

### 6.3 約束どうしの矛盾

- 約束には、**両方は守れない組み合わせ**がある。例：ドグマへの「本気の決闘」と、リーナへの「安全に帰す」。
- 矛盾は、**トトが気づいたときに帳面の上でつながって見える**【推奨】。気づくのは、矛盾を示す情報を得たとき（例：ドグマが決闘の相手にリーナを指名してきたとき）。最初から全部が見えるわけではない。
- 矛盾した約束を両方抱えたまま進むこともできる。そのとき、矛盾した二人を**会わせない**ことが、トトの仕事になる。

### 6.4 嘘はいつ、どう発覚するか

嘘は乱数ではなく、**決まった理由**で発覚する【推奨】。

| 発覚の理由 | 例 |
|---|---|
| **出会い**：嘘をつかれた人と、真実を知っている人が出会い、その話題になる | 夜、リーナとミントが同じ部屋で寝る。ミントが偽の書類のことを話す |
| **期限**：守れない約束の期限が来る | ドグマとの「火曜の決闘」 |
| **実物**：嘘と食い違うものを見る | ヴェラの視察で、物置に隠れている勇者一行が見つかる |
| **同席**：矛盾する約束をした二人が、同じ卓につく | 後半の峠の卓（すべての約束が一つの卓に集まる） |
| **見抜く**：嘘を見抜く人物 | ミント（同類）、ヴェラ（報告の食い違い） |

**プレイヤーは、発覚の危険を事前に読める**：帳面で「知っている人」を見れば、誰と誰を会わせると危ないかが分かる。城の人々の予定（朝に分かる範囲）と合わせて、どの場面に行くかを選ぶ。これが前半のドタバタになる。

### 6.5 打ち明ける・取り繕う・取り下げる

| 行動 | いつできるか | 相手の記憶に残るもの | 関係への影響 |
|---|---|---|---|
| **打ち明ける**（自分から嘘を明かす） | 発覚する前ならいつでも | 「嘘をつかれた」と「自分から言ってくれた」の両方 | その場で姿勢は下がる。だが、発覚した場合よりずっと浅い。リーナとハーゲンには特に効く |
| **取り繕う**（ばれかけた嘘を、別の嘘で塞ぐ） | 発覚しかけたとき | 何も残らない（うまくいけば）。新しい嘘が帳面に増える | その場はしのげる。嘘が嘘を呼び、知っている人が増える |
| **取り下げる**（守れない約束を、正直に言い直す） | 期限の前 | 「守れないと先に言ってくれた」 | 姿勢は下がるが、その代わりを添えれば、関係はむしろ深まることがある |
| （**発覚する**） | — | 「嘘をつかれた」「他人から聞いた」 | 関係が大きく変わる。相手が自分で動き出す（§7） |

### 6.6 嘘を単純な悪手にしないために

前半の嘘には、はっきりした合理性を持たせる【確定：依頼の方針】。

1. **時間が浮く**：「はい」はその場で終わる。1日3場面しかないので、全員に正直に向き合うことはできない。
2. **情報が足りないときの橋渡し**：相手の本当の望みが分からないうちは、「その代わり」は外れやすい。嘘で時間を稼ぎ、望みが分かってから正直に組み直す、という使い方ができる。
3. **ばれない嘘もある**：知っている人が少なく、会わせなければ、最後までばれない嘘もある。
4. **ガルザへの「はい」は、優しい嘘**：「穏やかに引退できる方法を探します」は、当てがなくても、ガルザを慰める。
5. **結末は嘘の数では決まらない**：結末を決めるのは、最後の網の形（§10）。前半に嘘をついても、⑩〜⑫で清算すれば、結末Aは目指せる。
6. **ただし、清算には手間がかかる**：嘘が多いほど、⑩の取り立ては多く、⑬で来てくれる人は少なく、峠の別室で詰める相手が増える。

### 6.7 関係の変化

関係は記憶から決まる（§4.1）。帳面には、一人ひとりの関係の種類と、**関係を変えた出来事**（「火曜の決闘を三度延ばした」「宝箱を約束どおり渡した」）が載る。プレイヤーは数値ではなく、出来事の積み重ねとして関係を見る。

## 7. 失敗とリカバリー

### 7.1 失敗は次の場面になる

| 失敗 | 何が起きるか（例） |
|---|---|
| **相手が怒って席を立つ** | 相手は自分で動き出す。ドグマはトトを待たずに、自分で勇者を探しに行く（新しい問題：ドグマとリーナが出会う） |
| **条件が悪くなる** | ボルドが「宝箱三つ」から「宝箱三つと年金」へ値を上げる |
| **新しい問題が起きる** | 約束を放っておいたら、ヴェラが代わりにその相手と話をつけていた（トトの頭越しに、別の約束ができている） |
| **別の人が割り込む** | ミントとの話し合いに、ピコが「面白そうな話だね」と入ってくる |
| **嘘が発覚する** | 相手の関係が変わり、相手が動く。その動きが別の約束を揺さぶる |
| **やり直しが必要になる** | 物別れのあと、相手の怒りが落ち着く（一晩たつ）と、もう一度会える。ただし、姿勢は「構える」から始まり、相手は前回のことを覚えている |

**ゲームオーバーはない**【推奨】。どの失敗も、物語の流れのどこかに合流する。⑩の「請求の日」と⑫の「立ち直り」は、どんな遊び方でも必ず来る。

### 7.2 ⑩「請求の日」：前半のすべてが返ってくる

⑩は物語として必ず起きる（ドグマの挙兵、教会の認定、リーナとの決別、課から外される）。**だが、その形と重さは、前半の帳面で変わる**【推奨】。

| 前半の帳面 | ⑩での違い（例） |
|---|---|
| ドグマへの先延ばしの数 | ドグマの軍の大きさ。ドグマが集めた強硬派の数 |
| ミントとの関係（共犯か、相談相手か） | 報告書の盛り方。ミントが⑩で撤回の覚悟を持つか |
| ボルドへの約束（城の待遇） | ボルドが城に残るか去るか |
| ピコに話したこと | 王が何を知っているか。峠の別室でのエドモンドの第一声 |
| リーナへの嘘と⑨の手紙 | ⑩の別れの言葉と、⑫の再会の難しさ |
| ヴェラへの報告の正確さ | ヴェラがトトを外すときの言葉。⑬で「計算を確かめに」来てくれるか |
| 城の部署の魔物たちとの関係 | ⑬の実演に、誰が来てくれるか |

**⑩の遊び方**：溜まった約束が、一人ずつ取り立てに来る。各場面でプレイヤーは、打ち明ける／取り下げる／取り繕う、を選ぶ。ここで取り繕えば、⑩はしのげるが、嘘は峠まで持ち越される。

### 7.3 ⑫の立ち直り

- ⑫のリーナとの交渉は、どんな遊び方でも必ず起きる。
- ここで正直に話せば、リーナは条件つきで戻ってくる（§8.4 の差は前半の帳面で変わる）。
- ここで取り繕い続けると、リーナは戻らない。結末Bの暗い変奏への道が開く（§10.2）。

## 8. 前半の交渉プレイ例（例A：リーナとの交渉）

### 8.1 場面

物語の④〜⑥。リーナの一行が宝箱を断った翌日。トトは一行と、城の応接室（という名の物置）で向き合う。
ヴェラには「交渉は順調です」と報告してある（⑤の嘘はすでに帳面にある）。今日が終わるまでに一行を「片づけ」なければ、ドグマの軍に回される。

### 8.2 状況

**卓の向こう**：リーナ、ボルド、ミント、ピコ。

| 人物 | 表向きの要求 | 本当の望み | 見えているしぐさ |
|---|---|---|---|
| リーナ | 魔王と戦わせて | カヤ村を救う。自分の力で何かを変える | 剣の柄を握っている。村の話になると、首のお守りを握る |
| ボルド | 宝箱をもらって帰る | 老後の蓄え。膝 | 宝箱をちらちら見る。膝をさする |
| ミント | 「討伐の形」が欲しい | 教会での地位 | 報告書の束を抱えている |
| ピコ | 劇的な場面を | 王への報告 | 何かを書き留めている |

**トトの手元**

| 種類 | 中身 |
|---|---|
| 品 | 宝箱（2つ。ヴェラの予算）、城の食券、ガルザの古い角（倉にあるのを知っている） |
| 約束 | 何でも作れる |
| 話の種 | 「ガルザは引退したい」（③）、「角を折られた魔王は玉座を降りる」（魔物の掟。ガルザから聞いた）、「角を折った勇者は王に願いを一つ言える」（人間の慣わし。ボルドの昔話から、またはこの場で探って知る）、「ドグマは本気の相手を探している」（③）、「罠課の職人は、本気で罠に挑んでくれる相手を探している」（③で罠課に寄っていれば） |
| 帳面 | ヴェラに「順調です」（嘘）、ドグマに「検討します」（先延ばし1回）、ガルザに「引退の方法を探します」 |

### 8.3 遊びの流れ（一例）

**① 様子を見る**
リーナは剣の柄を握ったまま、トトをまっすぐ見ている。ボルドは宝箱から目を離さない。一行の中で、すでに望みが割れていることが見える。

**② 宝箱を差し出す（いつもの手）**
- リーナ：宝箱を押し返す。姿勢は「構える」のまま。
- ボルド：指を折って数え始める（得の話に反応するしぐさ）。「二つか。前の担当は三つ出したぞ」（目をそらす。はったり）。
- リーナはボルドをにらむ。**一行の中の対立が表に出る。**

ここで、プレイヤーには選択肢がある。
- ボルドを先に味方にする（宝箱を渡す約束をする）→ ボルドがリーナを説得し始める。ただし、リーナは「お金で動く仲間」に苛立つ。
- ボルドのはったりを突く（「三つ出したことは一度もありません」）→ ボルドは笑って一目置く。
- ボルドは後回しにして、リーナを探る。

**③ リーナを探る：お守りを指す**
リーナはお守りを握り、少し黙ってから言う。「……カヤ村。税で、もう半分の家が空き家なの」。
姿勢が「聞く」に上がる。**表向きの「魔王を倒す」の裏に、村がある**ことが見える。

**④ リーナの要求：「魔王と戦わせて」**
リーナが自分から要求を卓に置く。プレイヤーの応じ方。

| 応じ方 | 何が起きるか |
|---|---|
| **はい** | 「分かりました、手配します」。リーナは手帳に書く。その場は収まる。**だが、トトにはできない約束**（ガルザは戦えない、ドグマに回せばリーナが傷つく）。嘘の約束として帳面に残る |
| **いいえ** | リーナは剣を抜きかける（姿勢「閉じる」）。ピコが「おっ」と身を乗り出す。ボルドが止めに入る。場面がこじれる |
| **その代わり** | 「魔王を倒す」ではなく「村を救う」に応える案を出す。たとえば**角の計画**（下）。読みが当たっていれば、リーナの姿勢が動く |
| **持ち帰る** | 「一晩ください」。宿題が生まれる。今日中に片づかないので、ヴェラの視察が近づく |

**⑤ 角の計画を差し出す（その代わり）**
トトは話の種「角を折った勇者は王に願いを一つ言える」と、約束「角を折る場を用意する」を組み合わせて差し出す。

ここで、**本当のことを言うかどうか**をプレイヤーが決める。

**嘘の道：「角を折るのは、あなた自身の力です」**
- リーナ：お守りから手を離し、身を乗り出す（「乗り出す」）。「本当に？ 王様に、村のことを言えるの？」
- 合意。**場面はここで終わる**。今日のうちに一行が片づき、ヴェラへの「順調です」も守れる。
- 帳面に残るもの：リーナへの嘘「角を折るのはあなたの力」。**知っている人：トト、ガルザ**（後に、ミントが偽の書類を作れば、ミントも）。
- 合意のあと、リーナがトトの手を握って言う。「ありがとう。また今度、ちゃんとお礼するね」。トトは反射的に「はい、また今度」と答える。**リーナの帳面に、約束がもう一つ増える**（後で効いてくる小さな笑い）。

**正直な道：「芝居です。でも、王様に会えるのは本当です」**
- リーナ：お守りを握ったまま、剣の柄に手が戻る（「構える」に下がる）。「芝居なんて、嫌」。
- **ここで終わりではない。** リーナは何を嫌がったのか。しぐさは剣の柄、つまり「自分の力で」に触れた。プレイヤーはここから、**「自分の力で」に応える案**を探す。
  - 罠課の職人を思い出す（本気で挑んでくれる相手を探している）。「角までの道は、罠課の本気の罠です。それは芝居じゃない」。
  - この案を出すには、**罠課の職人に話を通す必要がある**（持ち帰り → 次の場面で罠課へ）。
- リーナ：「……罠は、本物なんだね。なら、やる」。姿勢は「聞く」から「乗り出す」へ。ただし、合意の中身に「芝居の部分がある」ことを、リーナは知っている。
- 場面を一つ多く使う。今日中に片づかないかもしれない。ヴェラの視察と重なれば、隠す算段が必要になる。
- 帳面に残るもの：リーナとの約束「罠課の本気の試練」（嘘ではない）。罠課の職人への約束「本気の挑戦者を連れてくる」。リーナの記憶に「トトは本当のことを言った」。

**⑥ 一行の他の3人**
リーナと合意しても、一行は4人いる。
- **ミント**：「討伐の形にしてもらえますか」。ここで「はい、報告書は好きに書いてください」と言えば、**⑩の引き金**が帳面に入る（その場では、ただの親切に見える）。「その代わり、言い回しは一緒に考えましょう」と言えば、場面を一つ使うが、ミントは相談相手になる。
- **ピコ**：「角折りの場面、見せ場にしてね」。「はい」と言えば、ピコは喜んでその場面を王に詳しく報告する。
- **ボルド**：宝箱をまだ欲しがっている。「その代わり、食堂のコックが人手を探しています。年金つきです」と言えるのは、コックと話していた場合だけ。

### 8.4 その場の結果と、後々への影響

| | 嘘の道 | 正直な道 |
|---|---|---|
| その場 | 早い。一場面で片づく | 遅い。罠課への持ち帰りで場面を一つ多く使う |
| その日 | ヴェラの視察を無事に越えられる | ヴェラの視察と重なる危険がある（一行を隠す必要が出る） |
| ⑧（城の一週間） | リーナはトトを全面的に信じる。トトの頼みを何でも聞く（動かしやすい） | リーナは芝居の部分を知っている。ときどき「これも芝居？」と確かめに来る（手間がかかる） |
| ⑧の追加効果 | — | 罠課の職人がトトに恩を感じる（⑬の実演に来てくれる） |
| ⑩ | リーナは王から真実を聞く。**決別**。「私は、あなたの芝居の中で勇者をやっていたんだね」 | 芝居のことは知っているので、リーナの怒りは「税が魔物の命綱だったこと」と「⑨の手紙で何を書いたか」に向く（§11 G-3） |
| ⑫ | 再会は難しい。全部を打ち明けて、ようやく条件つきで戻る | 再会は比較的易しい。リーナが先に「一緒に考えよう」と言い出すこともある |

**どちらの道にも理由がある**：嘘の道は、前半を楽に、速く進められる。⑧で場面を節約できる分、他の人物（老商人、ガルザ、コック）との交渉に時間を使える。正直な道は、前半は手間がかかるが、後半の味方を増やす。

## 9. 後半の交渉プレイ例（例B：峠の卓）

### 9.1 場面

物語の⑭。夜明け前の峠。ハーゲンの辺境軍とドグマの軍がにらみ合う真ん中に、罠課の仕掛けで卓がせり上がる。
**夜明けが期限**。夜明けまでに、別室に行けるのは**5回**【推奨】。

### 9.2 卓につく人と、それぞれの要求と恐れ

| 人物 | 公の卓での要求（立場） | 別室で出てくる恐れ | 決裂したらどうなるか |
|---|---|---|---|
| エドモンド | 「双方、兵を引け」 | 都の貴族に見放されて王座を追われること | 王座を失う。強硬派の時代 |
| ガルザ | 「わしの首で済むなら」 | 魔物たちが冬に飢えること。ドグマに嫌われたまま終わること | 魔物が飢える |
| ドグマ | 「ガルザの本物の首を」 | 自分の30年が無意味だったこと | 本当の戦争（そして負ける） |
| ハーゲン | 「夜明けとともに谷へ入る」 | 村が消えること。魔物と組んで裏切り者と呼ばれること | 戦場は自分の村。農民が死ぬ |
| ミント | （黙っている） | 報告書の撤回で、教会での地位を失うこと | 自分の報告書で戦争が起きる |
| ヴェラ | 「計算を確かめに来ただけよ」 | 理想論で城が冬を越せないこと | 城が潰れる |
| リーナ | 「村を勘定に入れて」 | 何も変えられないこと | 村が戦場になる |

**プレイヤーに見えているもの**：公の卓での要求と、各人物のしぐさ。そして、帳面。**帳面には前半の約束と嘘が全部載っている**。峠の卓は、それらがすべて一つの場に集まる場面でもある（§6.4 の「同席」）。

### 9.3 プレイヤーが把握している情報（遊び方で変わる）

| 情報 | 入手の経路 | 知らない場合 |
|---|---|---|
| 討魔の勅令の条文 | ヴェラ（⑨の帳簿室）、エドモンド（⑩の謁見の報告をリーナから） | 第四条が王の許可なしで動くことが分からず、エドモンドに「止めてください」と頼んで空振りする |
| 貴族の免除（第二条） | 帳簿、ハーゲンの愚痴、老商人の言葉（⑧） | 「辺境の支持」という取引を思いつけない |
| ガルザがドグマに黙っていた理由 | ガルザと盆栽の場面を重ねていれば（⑧） | ドグマの別室で、ガルザを連れてくる理由が分からない |
| 辺境は人手が足りない | ⑬のカヤ村、リーナの話 | 「魔物の働き手」の取引が組めない |
| 死んだことになっている魔王は署名できない | ミントとの会話、教会の手続き | ミントの撤回の必要性に、卓の終盤で気づく（時間が足りなくなる） |

### 9.4 遊びの流れ（一例）

**① 公の卓：トトが最初に打ち明ける**
プレイヤーは、何をどこまで打ち明けるかを選ぶ。
- 全部（角の細工、ミントの報告書、ドグマへの嘘）を打ち明ければ、「この小鬼は自分に不利なことも言う」として、**仲介役の信用**を得る。別室の回数が1回増える（相手が別室に応じてくれる）【推奨】。
- 一部だけにすれば、ミントやドグマが残りを指摘して、信用を失う。
- 何も打ち明けずに進めることもできる（暗い変奏への道。§10.2）。

**打ち明けても、誰も続いて告白はしない**（物語のとおり）。ハーゲン「それで？ お前が嘘つきだと分かっただけだ」。卓は崩れかける。

**② 別室1：エドモンド**
- 公の卓では「双方、兵を引け」と言うだけ。しぐさ：王冠の位置を何度も直す（王座への恐れ）。
- 探ると、エドモンドは穏やかに「はい、なんとかしよう」と言う。**エドモンドの「はい」は約束にならない**（帳面に残らない）。プレイヤーは、トト自身の昔の姿を見ることになる。
- 「いつ、誰に、何を」と詰めると、エドモンドの恐れが出てくる。「真実を言えば、都の貴族が私を降ろす」。
- **トトが組む取引**：「都の貴族の代わりに、辺境の諸侯があなたを支持するなら？」——だが、それはハーゲンの同意がなければ成り立たない。
- **つなぐ**：「ハーゲンが支持するなら、王は30年の真実を打ち明け、第二条を撤廃する」。まだ片側だけの条件つきの約束。

**③ 別室2：ハーゲン**
- 公の卓では「夜明けとともに谷へ入る」。しぐさ：地図の北の谷を指で押さえているが、領民（自分の兵の農民たち）のほうを何度も振り返る。
- ハーゲンは**言葉だけの約束を割り引く**。トトが「王が真実を打ち明けます」と言っても、「10年聞いた」。
- 効くのは実物と、リーナの言葉。⑬の実演（水車と橋）が成功していれば、ハーゲンは最初から「聞く」姿勢で座る。リーナを連れてくれば、もう一段上がる。
- ハーゲンの条件：「なぜ30年、辺境だけが払わされたのか。王が公の場で言うこと」「第二条の撤廃」「辺境の即時免税」。
- 谷については、「谷の魔物たちが辺境の村で働く」案に、ハーゲンは迷う（しぐさ：地図から指を離しかけて、また戻す）。**恐れ「裏切り者と呼ばれること」**が残っている。
  - リーナが「村の人は、水車を直したのが誰か見てる」と言えば、指が離れる。
  - リーナがいなければ、ハーゲンは雇用の取り決めを拒む → 結末C（痛みのある和平）の道。
- **つなぐ**：「王が公に打ち明け、第二条を撤廃するなら、辺境の諸侯は王を支持し、谷の奪還をやめる」。

**エドモンドとハーゲンの約束は、互いに相手待ちになっている**。どちらも先には動かない。これは公の卓で**同時に開く**しかない（⑥）。

**④ 拒否された場合の展開**
たとえば、ハーゲンが別室でトトの案を拒んで席を立ったとする。
- ハーゲンは公の卓に戻り、「夜明けまで待つ必要はない」と兵に合図しかける。**夜明けが一段近づく**（別室の残り回数が1回減る）。
- 新しい問題：辺境の兵が動いたのを見て、ドグマの兵も前に出る。
- プレイヤーの選択：ハーゲンを追うか（リーナを連れて）、ドグマを先に抑えるか、エドモンドを公の卓で動かすか。
- ハーゲンの拒否のしぐさ（地図の上で拳を握った）から、**何が足りなかったか**を読み直せる。

**⑤ 別室3〜4：ガルザとドグマ**
- ドグマは公の卓で「ガルザの首を」と言い、斧の柄を握り直している。トトが一人で別室に誘うと、ドグマは「お前の言葉は聞かん」（前半の先延ばしの記憶）。
- **ガルザを先に動かす必要がある**。ガルザの恐れは「ドグマに嫌われたまま終わること」。ガルザの条件は「魔物たちの冬が保証されること」。
  - 冬の保証は**ヴェラ**の条件（前払いの基金、書面の契約）と、**エドモンド**の第二条撤廃（貴族の税が基金になる）につながっている。
- ガルザがドグマの別室に一緒に行けば、ガルザは自分の口で、なぜドグマにだけ黙っていたかを話す（「おぬしが本気でいてくれたから、この芝居は30年もった」）。
- ドグマのしぐさ：斧から手が離れる。**真実を正面から渡されれば、誰よりも早く切り替える**（ドグマの交渉ロジック）。
- ドグマの条件：「合同の国境守備隊の長」。これはハーゲンの「魔物の働き手を受け入れる」とつながる（働き手を守る役目だから）。

**⑥ 別室5：ミント（または、ヴェラ）**
- 残り1回。ミントの撤回がなければ、**死んだことになっている魔王は署名できない**。ヴェラの条件も残っている。
- どちらに行くか、プレイヤーが選ぶ。
  - 前半でミントと相談相手の関係を作っていれば、ミントは公の卓で、別室なしで自分から撤回する。別室はヴェラに使える。
  - 共犯の関係なら、ミントは別室で「あなたも全部言ったんだから」と言って撤回する。ヴェラは公の卓で、条件を一つずつ卓に置いてくる。
  - 関係がなければ、ミントは撤回しない。時間切れ → 結末B（公表できず、秘密のまま仕組みを直す）の道。

**⑦ 公の卓：同時に開く**
夜明け。トトは、別室で組んだ条件つきの約束を、すべて公の卓に並べる。
- エドモンドとハーゲンの互いに相手待ちの約束を、同時に開く。
- ガルザがドグマに公に詫びる。
- ミントが報告書を撤回する。
- ヴェラが自分の条件を確かめ、最後に署名する（「計算は合ってる。……信じたわけじゃないわよ」）。

### 9.5 複数の合意の組み立て方

峠の卓の合意は、別々の取引の**つながり**でできている。

```
 ハーゲンの支持 ←→ エドモンドの告白と第二条撤廃       （互いに相手待ち：同時に開く）
        │                    │
        │                    └→ 貴族の税 → 冬越しの基金 → ヴェラの条件
        │                                              │
        └→ 魔物の働き手の受け入れ ←── ドグマの守備隊      └→ ガルザの条件（魔物の冬）
                                       ↑                         │
                                ガルザの謝罪と理由 ←──────────────┘
 ミントの撤回 → ガルザが「生きている魔王」として署名できる
```

- **一つの取引が崩れると、つながっている取引も揺らぐ**。プレイヤーは、どこから固めるかを選ぶ。
- **組み方は一通りではない**【推奨】。例：
  - ハーゲンが雇用を拒んでも、ヴェラの基金だけで最初の冬は越せる（結末C寄り）。
  - ドグマを動かせなくても、ガルザの退位と和平は成るが、ドグマは追放される（結末C）。
  - エドモンドが公表を拒み、ヴェラが秘密のまま仕組みを直す案を出す（結末B）。

### 9.6 最終的な合意の決まり方

夜明けに公の卓で開いたとき、**どの取引が成り立っているか**で決まる（§10）。プレイヤーが別室で何を組んだかが、そのまま合意の中身になる。

| | 前半（例A） | 後半（例B） |

## 10. エンディングへの影響

### 10.1 結末の決まり方

峠の卓で、夜明けに**どの取引が成り立ったか**で決まる【推奨】。過去の嘘の数では決まらない（§6.6）。

| 結末 | 成り立っている取引（物語の水準） |
|---|---|
| **A 本当の和平** | エドモンド⇔ハーゲン（同時に開く）、ガルザ⇔ドグマ、ハーゲン⇔ドグマ（働き手と守備隊）、ヴェラの条件、ミントの撤回。**すべての取引が、人と人の直接の約束**（トトを通らない） |
| **B 新しい八百長** | 公表の取引（エドモンドの告白）が成り立たない。ヴェラの「秘密のまま直す」案が採られる。ドグマとハーゲンへの約束は、**トトを通した、真実を伏せた約束**のまま |
| **C 痛みのある和平** | 公表は成り立つが、一人の恐れが取り除かれていない（ドグマ、ハーゲンの雇用、エドモンドの王座のどれか）。誰が代償を払うかで、Cの中身が変わる |
| **D 決裂** | 夜明けまでに、エドモンド⇔ハーゲンの取引が成り立たない。または、ハーゲンかドグマが兵を動かす |

### 10.2 結末Bの暗い変奏（最後まで嘘をつき続けた場合）

- ⑫でリーナに取り繕った場合、リーナは戻らない。⑬の実演は、トトが嘘で動かさなかった少数の魔物だけでやることになる（ハーゲンの姿勢が下がる）。
- 峠の卓で何も打ち明けずに進めると、**新しい嘘で取引をまとめる道**が開く。トトは嘘が上手いので、取引はまとまる。
  - ドグマには偽の勝利、ハーゲンには偽の約束、エドモンドとガルザには「あと10年もつ」仕組み。
  - 帳面は、また**トトを真ん中にした星**に戻る。しかも前よりも大きな星。
- 結果：結末Bの暗い変奏。トトは昇進する。最後の場面は冒頭と同じ構図（§03 の8.2）。
- 嘘でまとめようとして失敗すれば、結末D。

**扱い**：U-S7 は Phase 3 で【未決】のまま。本書は B の変奏として設計し、独立した結末にする場合でも、仕組みは変わらないようにしている。

### 10.3 結末に至るまでの振り返り【推奨・未決 G-8】
- 毎晩、トトは母に手紙を書く（物語にすでにある道具）。手紙には、その日トトがした約束と嘘が、トトの言葉で（言い訳まじりに）書かれる。理論の解説はしない。
- 結末のあとに、帳面の全体（星から網への変化）をもう一度見せる。「あり得た別の取引」は、別室で組まなかった取引として示す。
- 交渉理論の名前を出すかどうかは判断が必要（G-8）。

### 11.3 設計上のリスク

| リスク | 内容 | 対策の方向 |
|---|---|---|
| **しぐさが伝わらない** | プレイヤーがしぐさを見落とすと、読みの遊びが成り立たず、ただの会話になる | 一人ひとりのしぐさを少なく、はっきりさせる（2〜3種類）。同じしぐさを繰り返す。ボルドやピコが代わりに口に出すこともある（「おい、勇者さん、お守り握ってるぞ」） |
| **「その代わり」がクイズになる** | 正しい品を当てる遊びになる | 応える品を複数、深さに差をつける。外れても何が足りないかを見せる（§3.4） |
| **城の一週間の出会いの仕組みが重い** | 人物の予定と出会いの組み合わせが増えすぎると、作るのも遊ぶのも大変 | 人物の予定は**台本で決める**（自由に動き回るのではない）。出会いで発覚するかどうかの条件は、決まった規則で判定する。城の場所は6か所程度、人物は10人程度に抑える |
| **峠の網が表計算になる** | つながりを全部頭に入れないと解けない、パズルになる | 取引は人物の言葉と恐れとして出てくる（「王が言うなら」）。つながりを抽象的な図で見せすぎない（UIの段階で検討）。人数は7人を超えない |
| **嘘と正直のバランス** | 嘘が強すぎると正直に意味がなく、正直が強すぎると前半の迷いがなくなる | 遊んで調整する。物語の骨格（⑩と⑫は必ず来る）があるので、どちらに振れてもゲームは壊れない |
| **⑩が「罰の時間」に感じられる** | 溜まった約束が一度に返ってくるのが、ただの罰に見える | 取り立ての場面を笑いの場面として作る（ドグマの「火曜はもう七回目だ」）。打ち明ける・取り下げるで、その場で状況を変えられるようにする |
| **台詞の量** | 行動 × 人物 × 状況で、反応の台詞が爆発する | 反応はしぐさと姿勢を主にして、台詞は短く、使い回せるものにする。大事な場面だけ固有の台詞にする |
| **日英対応** | しぐさの意味や言葉遊び（「はい」）が英語に移るか | 「はい」は "Yes" で成り立つ。しぐさは言語に依存しない。社交辞令のずれ（「また今度」）は英語の言い回しで置き換える |

## 12. 次の段階について

本書はゲームシステムの設計までです。UIの詳細、画面、見た目、実装、技術選定には進んでいません。

2. 「はい」の気持ちよさと、帳面がきしむ不安が、両方感じられるか。
