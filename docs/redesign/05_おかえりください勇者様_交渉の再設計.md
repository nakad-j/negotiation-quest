# 05 おかえりください勇者様：交渉の再設計（提案）

- 作成日：2026-11-24
- 対象：`prototype/okaeri_v1/`（試作 v1）の交渉部分の作り直し
- 状態：提案。**実装は未着手**（承認後に着手）
- 交渉の土台：クリス・ヴォス『逆転交渉術（Never Split the Difference）』
- 用語の扱い：技法の名前（ミラーリング、ラベリングなど）は、この文書の中だけで使う。**ゲーム画面には一切出さない。**

---

## 0. ひとことで

> **「答えを探すゲーム」から「相手が話したくなる会話をするゲーム」へ。**

v1 は「質問を選ぶ → 本当の望みが手に入る → 望み × 城の手段 を組み合わせる」という、情報集めのパズルだった。
新しい形では、**相手の言葉をどう受け止め、どう返すか**で相手の心の開き方が変わり、話す内容も変わる。本当の事情は、質問ひとつで手に入るものではなく、会話の積み重ねで**少しずつ、ときには食い違いながら**見えてくる。

---

## 1. 新しい基本ループ

### 一日（変えない）
来客3人 → 一人ずつ応対 → 日暮れ、魔王様のひとこと → 一日の報告（元気・評判・その後）

### 一人の客（ここを作り直す）

```
 第一声（表向きの要求）
   ↓
 ┌─ 会話のやりとり（数ターン） ←──────────┐
 │   相手の言葉を受ける／返す／黙って待つ      │
 │   相手の反応：表情・しぐさ・ひとこと        │
 │   トトのメモに「気がかり」が書き足されていく │
 └──→ まとめて返す（「……そうなんだよ」が出るか）
           ↓
       一緒に考える／提案 → 相手の反論・逆提案 → 調整
           ↓
 決着：合意して帰ってもらう／👑 魔王様に通す／🚪 お引き取り願う
       （会話がこじれすぎると、相手が自分で動き出す）
```

- 決まった手順を全員に踏ませるわけではない。ミミのように「まとめ」の前に事態が動く客もいれば、ハンナのように、提案より先に相手の思い違いをほどく必要がある客もいる。
- 1人あたり **8〜15回のやりとり、3〜5分**。

## 2. 会話と交渉のしくみ

### 2.1 一回のやりとりで、プレイヤーにできること

| 操作 | 画面での見え方 | 中身 |
|---|---|---|
| **返事を選ぶ** | 吹き出しの下に、トトのせりふが**3つ**（短い文） | 共感・問いかけ・ラベル・提案などが、ふつうのせりふとして混ざっている |
| **言葉を拾う** | 相手の吹き出しの中で、いくつかの言葉が**うっすら下線つき**。クリックすると、トトがその言葉をそのまま聞き返す（例：「……一騎打ち？」） | ミラーリング。拾う言葉によって、話の広がる方向が変わる |
| **黙って待つ** | 小さな「……」ボタン（いつでも押せる） | 間（ま）。相手によっては沈黙に耐えきれず、もう一言しゃべる。ただし、せっかちな相手は苛立つ |
| **姿を見る** | 相手の体や持ち物の🔍札（v1 と同じ） | 調べると、**次の返事の候補に、それを話題にしたせりふが1つ混ざる**（2.4） |
| **会話をやめる** | 画面の端の「👑 魔王様に通す」「🚪 お引き取り願う」 | 交渉しない道（BATNA。6章） |

**選択肢は常に3つ＋「言葉を拾う」＋「……」**。それ以上は並べない。せりふは10〜25字程度の、トトらしい口語。

### 2.2 相手の内側（画面には数字で出さない）

客ごとに、隠れた値は**2つだけ**。

| 値 | 意味 | 画面での見え方 |
|---|---|---|
| **こころの開き**（0〜3） | どこまで話してくれるか | 0：腕組み・目をそらす・返事が短い ／ 1：こちらを見る ／ 2：身を乗り出す、話が長くなる ／ 3：声が小さくなる、本音（吹き出しが柔らかい色になる） |
| **いらだち**（0〜3） | どこまで我慢してくれるか | 貧乏ゆすり、拳、声が大きくなる（太字・揺れる吹き出し）。3を越えると、相手が自分の手で動き出す |

- 同じ質問でも、**こころの開きが足りないうちは浅い答えしか返ってこない**（「お前には関係ない」）。怒りはしないが、情報も出ない。これが「まだ早かった」という、正解・不正解ではない失敗になる。
- 値は増えたり減ったりする。プレイヤーは表情・しぐさ・返事の長さで読む。

### 2.3 話の「たね」と深さ

客の事情を、**いくつかの話題（たね）×深さ（1〜3）**で持っておく。会話の分岐を一本の木で書かずに済ませるためのしくみ。

例（レオン）：「魔王」「証」「勇者協会」「家族」「鎧」「腕前」

- 話題に触れたとき、返ってくる答えは**その話題の深さ**と**今のこころの開き**で決まる。
- 深さ3まで届いた話題が、トトのメモで「確かな気がかり」になる。
- ミラーリング・ラベル・問いかけは、どれも「どの話題を、どう深めるか」の違いとして作る。

これで、客1人あたりのデータは「話題×深さ×開きのしきい値」の短い表＋特別な場面いくつかで済む（7章）。

### 2.4 観察は、会話の材料になる

v1 では、調べると事実がメモに入った。新しい形では、**調べると「話のきっかけ」が1つ手に入る**。

- 震える手を見る → 次の候補に「遠くから来たんだね。少し休む？」（共感）が混ざる
- 手紙を見る → 「その手紙、大事そうだね」（ラベル）が混ざる
- 言葉と姿が食い違うとき（威勢はいいのに手が震えている）に、ラベルが効く場面が生まれる

観察だけでは何も確定しない。**会話に使って初めて意味が出る。**

### 2.5 トトのメモ（v1 の「わかったこと」の作り直し）

- 「言い分／本当の望み／手がかり／弱み」の区分は**やめる**。
- トトの手書きのひとことメモにする。確かさは書き方で表す。
  - 「証がほしい……らしい」（推測）
  - 「名を上げたいわけじゃない（本人いわく）」（相手の否定）
  - 「妹と母さんを、手当で食べさせている」（確か。太字）
- **間違ったメモも残る**。思い違いをしたまま「まとめ」に進むこともできる（3.6）。
- メモはクリックして選ぶものではない。読んで考えるためのもの。

## 3. 『逆転交渉術』の技法を、どう遊びにするか

技法名はプレイヤーに見せない。**どのせりふを選んでも、ふつうの会話に聞こえること**を最優先にする。

| 技法 | ゲームでの形 | 効いたとき | 外したとき |
|---|---|---|---|
| **ミラーリング** | 相手の吹き出しの下線つきの言葉をクリック → トトが聞き返す「……持ち帰る？」 | 相手がその話題を一段深く話す。こころの開き +1 になりやすい | 浅い言葉を拾うと、同じ話をくり返すだけ（失敗ではなく遠回り） |
| **ラベリング** | 「〜みたいだね」「〜なんじゃない？」型のせりふ。**気持ちや事情の推測** | 図星なら黙りこむ → ぽつりと本音。開き +1 | **外れても情報が出る**。「名なんかどうでもいい！」と否定しながら、本当は何なのかを言いかける。いらだち +1 のことも |
| **共感（タクティカル・エンパシー）** | 相手の立場を受け止めるせりふ。「遠くから来たんだね」「そりゃ、腹も立つよね」 | いらだち −1。開きの土台になる | 開き0のうちに深い共感を言うと「わかったような口をきくな」 |
| **問いかけ（どう・何）** | 「その証がないと、何が困るの？」「どうしたら、手ぶらで帰らずに済むかな？」 | 相手が自分で考えはじめ、解決の案を**相手の口から**言わせられる | 開きが足りないと「関係ないだろ」。「なんで？」と聞くせりふも混ぜる。**自然に見えるが、責めているように聞こえていらだちが上がる** |
| **「いいえ」と言える質問** | 「戦わずに帰るなんて、論外……だよね？」「巡回を全部やめろって話じゃない……よね？」 | 相手が「……いや、そうとも限らない」と、自分から一歩動く | 早すぎると「そうだ、論外だ」で終わる（害はない） |
| **まとめ（「そうなんだよ」）** | メモが一定量たまると、選択肢に**まとめのせりふ**が現れる。トトがそれまでの話を、自分の言葉でつなぐ | 「……そうなんだよ」と相手が深く息をつく。**開き3・いらだち0**。提案が通りやすくなる | 間違ったメモが混ざると「まあ……そんなとこだ」。**気のない同意**で、提案は通りにくいまま |
| **相手の言いそうな悪口を先に言う**（補助） | 冒頭の選択肢に「どうせ追い返されると思ってるよね」 | 身構えがゆるむ | 使わなくてもよい。v2 では1人だけに入れて様子を見る |

### 3.1 「そうなんだよ」と「まあ、そんなとこだ」の区別

ヴォスの言う、本当の合意（That's right）と、気のない同意（You're right）の違いを、そのまま一番の手ごたえにする。

- **「……そうなんだよ」**：吹き出しが柔らかい色に変わり、客が肩の力を抜く絵。トトのメモの気がかりが**一行にまとまる**（例：「妹たちを食べさせるために、手ぶらでは帰れない」）。プレイヤーへのごほうびの瞬間。
- **「まあ……そんなとこだ」**：絵は変わらない。プレイヤーは「何かずれている」と感じて、もう少し聞くこともできるし、そのまま提案に進むこともできる。

### 3.2 失敗が「明らかな不正解」にならないために

- 3つの選択肢は、**どれもトトが言いそうな、悪くないせりふ**にする。「なんで魔王と戦いたいの？」は自然だが、責める調子に聞こえる。「もう帰ったら？」のような、明らかに悪い選択肢は置かない。
- 外したラベルでも情報が出る。早すぎた質問は、怒らせずにかわされるだけ。
- いらだちが上がる選択肢には、**必ず見返りがある**（例：いらだちは上がるが、言い分の矛盾がはっきりする）。
- 1回のミスで決裂しない。いらだち3を越えるには、少なくとも3回のつまずきが要る。

## 4. 自然な会話と、感情の見せ方

### 4.1 せりふの約束ごと

- トトは丁寧すぎない口語（「へえ」「そうなんだ」「……大変だったね」）。客によって少し変える（ミミには、やさしく短く）。
- **禁止**：「つまり〜ということですね」「あなたの本当の目的は〜」「〜と理解しました」。まとめのせりふも、トトの言葉でつなぐ（例：「手ぶらじゃ帰れないんだ。妹さんたちのために」）。
- 客は、**問われたことに全部は答えない**。話をそらす、言いかけてやめる、怒って違うことを言う。
- 1つの吹き出しは**2文まで**。長い独白は置かない。

### 4.2 感情の見せ方（3段）

1. **しぐさ**（いちばん先、ことばより早い）：目をそらす、拳を握る、袋を抱きしめる。絵の切り替え＋小さな注記「（目をそらした）」
2. **姿勢**：こころの開き0〜3を、体の向き・距離で（v1 の lina_v1 と同じ手法）
3. **ことば**：吹き出しの長さ・強さ。いらだちが高いと太字で短く、開きが高いと長く、語尾が弱くなる

### 4.3 相手が「わかってもらえた」と感じているかの合図

| 合図 | 意味 |
|---|---|
| 吹き出しが長くなる、自分から話題を足してくる | 開き2以上 |
| 間を置いてから話す、声が小さい（細い文字） | 本音に近い |
| 「……そうなんだよ」＋柔らかい色の吹き出し | まとめが届いた |
| 「お前に何がわかる」「関係ないだろ」 | まだ早い |
| 「まあ、そんなとこだ」 | ずれている |

## 5. 情報集めと観察の位置づけ

- 観察は**最初の一言の手がかり**。v1 の「調べると事実が入る」はやめ、「話のきっかけが増える」にする（2.4）。
- 「本当の望み」はどこにも明示しない。**メモと、相手の「そうなんだよ」で確かめる**しかない。
- 一部の事情は、最後まで確かめずに終わってもよい（例：レオンの腕前。本人は最後まで「弱い」とは言わない。震える手と、新品の剣と、スライムの話から推し量る）。
- **「弱み」のしくみは廃止する。** 弱みを突いて黙らせる代わりに、気がかりを理解したうえで**安心させる**（ラベル・共感・逆提案）ことで動かす。
  - 例：v1 の「スライム二匹半を持ち出す」は、「……本当は、戦いたくないんじゃない？」という**ラベル**として、開きが十分なときだけ効く形に変える。開きが低いうちに言うと、怒りを買う。

## 6. 提案・逆提案・BATNA

### 6.1 提案の出し方

v1 の「望み × 城の手段（7つ）」の格子は**やめる**。代わりに：

1. **まず相手に考えさせる**：「どうしたら、手ぶらで帰らずに済むかな？」と聞くと、相手が自分の条件を口にする（「……せめて、魔王に会ったって証があれば」）。**相手が言った条件は、相手が自分で出した案として受け入れられやすい。**
2. **トトの案**は、会話の流れの中で選択肢として出てくる（3択のうち1〜2つ）。中身は、v1 の城の手段（証書、罠課の芝居、城で雇う、工兵、兵、薬師、魔王様に一目）を**せりふの形で**使う。
   - どの案が候補に出るかは、それまでに届いた話題で決まる。「家族」まで話が届いていなければ、「城で雇う」案は出てこない。
3. 「いいえ」と言える形の提案もある：「勇者が魔王の城で働くなんて、ありえない……かな？」

### 6.2 反論と調整

- 客の反論は、**気がかりの形**で返ってくる（「でも、城で働いてるなんて知れたら、勇者の名が……」）。
- プレイヤーは**ラベルで受け止める**（「勇者でいられなくなるのが、怖いんだね」）→ 客が条件を言い直す → **案を少し変える**（「肩書きは『勇者』のまま、書状に書いてもらおう」）。
- 「調整」は新しい操作ではなく、**会話の続き**として行う。

### 6.3 合意の条件（中身は簡単に保つ）

- 合意できるのは、**その客の「核」の気がかり（1〜2個）に案が応えていて**、かつ **こころの開き2以上** のとき。
- 「そうなんだよ」を得ていれば、条件の一部が欠けていても受け入れる（例：協会が信じるかは半々、という証書だけの案でも、レオンは納得して帰る）。
- 合意の形が違えば、その後（一日の報告）も変わる。v1 の結末の文章はそのまま使える。

### 6.4 BATNA（交渉しない道）

- 「👑 魔王様に通す」「🚪 お引き取り願う」は**いつでも押せる**ボタンとして残す（v1 と同じ位置）。
- 結果は v1 と同じく、客の隠れた強さ・魔王様の元気・客の側の代わりの手で決まる。
- **会話の内容によって、BATNA の結果が変わる**：
  - 話を聞いてから「お引き取り願う」と、客の態度が違う（レオンはしょんぼり帰る／何も聞かずに断ると、魔王の間に乗り込む）。
  - ハンナは、いらだちが上がると**署名の巻物を取り出して脅す**。これは客側の BATNA の提示で、トトは「追い詰められてるんだね」と受け止めることもできる。
- BATNA を説明する文章は出さない。**魔王様の元気（ドアの向こうの絵）と、客が見せる「代わりの手」**で感じさせる。

## 7. 3人の客の作り直し

v1 の人物・事情・結末は活かす。**会話の「たね」と、効くせりふの傾向**を客ごとに変えて、同じ型の繰り返しにしない。

### レオン（勇者）── 見栄を張る若者
- 第一声：「魔王はどこだ！ 一騎打ちを申し込む！」
- たね：魔王／証／勇者協会／家族／鎧／腕前
- 効くもの：**ミラーリング**（自分から話したがる）、**遅めのラベル**（「ひとりで背負ってるんだね」）
- 効かないもの：「なんで？」（意地になる）、早すぎる「本当は戦いたくないんじゃない？」
- 核の気がかり：家族を食べさせる手当／勇者の面目
- 合意の例：勇者体験の城の勇者役（肩書きつき）、証書＋芝居の一騎打ち、魔王様と握手
- BATNA：弱いので戦わせても勝てる。ただし評判が下がり、協会がもっと強い勇者を送る
- 詳しい会話例は9章

### ハンナ（農婦）── 怒っているが、本当は怖い
- 第一声：「巡回をやめさせて！」
- たね：畑／巡回／橋／山賊／村のみんな（署名）
- 効くもの：**共感**（怒りを受け止める）、**「いいえ」と言える質問**（「巡回を全部やめろって話じゃない……よね？」→「……違うわ」と、本人が自分の言い分の矛盾に気づく）
- 効かないもの：最初から理屈（「巡回がないと山賊が」）を言う → 「説教しないで！」。**正しいことでも、言う順番を間違えると怒らせる**、を体験させる
- いらだちが上がると、署名の巻物を出す（客側の BATNA）
- 核の気がかり：刈り入れ／村の安全
- 合意の例：橋を直す＋それまで遠回り、など（v1 と同じ）

### ミミ（迷子）── 言葉が足りない子ども
- 第一声：「まおうさまに、あいたいの」
- たね：袋の中／おっきいトカゲさん／おばあちゃん／けが
- 効くもの：**ラベル**（「こわかったね」）、**黙って待つ**（ミミは沈黙のあとに大事なことを言う）
- 効かないもの：**問いかけ**（「どうしたらいいと思う？」→「……わかんない」）。大人向けの技法がそのままでは効かない、を体験させる
- 時間の圧力：窓の影（v1 と同じ）。会話が長引くと母竜が来る
- 見せ場：母竜が来たあと、**母竜との「ことばのない交渉」**。うなり声としぐさに、ラベルだけで応える（「……子どもが心配なんだね」）。短く2〜3手
- 合意の例：薬師で治して返す、魔王様が話をつける、など（v1 と同じ）

## 8. v1 から残すもの・変えるもの・捨てるもの

| 区分 | 項目 | 理由 |
|---|---|---|
| **残す** | トトとガルザ様の関係（腰痛・盆栽・「わしを呼ぶな」） | 笑いと、魔王様に頼らない理由づけ |
| 残す | 城の受付の画面構成（机・扉の向こうの魔王様・窓） | 一目で状況がわかる |
| 残す | 客の絵と、体・持ち物の🔍札 | 観察の楽しさ。役割だけ変える（2.4） |
| 残す | レオン・ハンナ・ミミの人物と事情、意外さ | 好評。会話の作りだけ変える |

## 9. 会話例：レオン

【 】は画面の変化。(開)＝こころの開き、(苛)＝いらだち。いずれもプレイヤーには数字で見せない。
最初は 開0・苛1（威勢はいいが、身構えている）。

### 9.1 出会い

> **レオン**：「魔王はどこだ！ 勇者レオン、魔王に<u>一騎打ち</u>を申し込む！」
> 【胸を張る。手は剣の柄。籠手の指先がかすかに震えている（🔍「手」が調べられる）】

| トトの返事 | レオンの反応 |
|---|---|
| ①（「一騎打ち」を拾う）「……一騎打ち？」 | 「そうだ。正々堂々、一対一だ。……結果さえ<u>持ち帰れれば</u>、それでいい」【少し得意げ。開0→1】 |
| ②「なんでまた、魔王様と？」 | 「勇者だからに決まってるだろう！」【声が大きくなる。苛+1。情報なし】 |
| ③「魔王様はいまお休み中で……」 | 「なら起こせ！」【苛+1。ただし「魔王様が疲れている」ことを口にしたので、あとで「戦ってもいいが、魔王様は本調子じゃない」と BATNA を意識させるきっかけになる】 |
| ④（🔍手を見たあと）「遠くから来たんだね。少し座る？」 | 「す、座らん！ ……三日、歩きどおしだったがな」【苛−1。たね「腕前」の入口が開く】 |

### 9.2 「持ち帰る」をめぐって（①を選んだ場合）

> **レオン**：「結果さえ<u>持ち帰れれば</u>、それでいい」

| トトの返事 | レオンの反応 |
|---|---|
| ①（「持ち帰れれば」を拾う）「……持ち帰る？」 | 「……ああ。持って帰らなきゃならないんだ。魔王と戦った、っていう<u>証</u>をな」【目をそらす。メモ：「証を持ち帰りたい……らしい」】 |
| ②「勝てば、名が上がるもんね」（外れたラベル） | 「名なんかどうでもいい！ ……どうでもいいんだ、そんなものは」【苛+1。メモ：「名を上げたいわけじゃない（本人いわく）」。**外れたけれど「名声ではない何か」が見えた**】 |
| ③「誰かに、見せなきゃいけないみたいだね」（当たりのラベル） | 「……勇者協会にな」【黙りこんでから、ぽつり。開1→2。たね「勇者協会」が開く】 |

### 9.3 深いところへ（開2 のとき）

> **レオン**：「……勇者協会にな。証がなきゃ、来月から<u>手当</u>が出ない」

| トトの返事 | レオンの反応 |
|---|---|
| ①（「手当」を拾う）「手当？」 | 「勇者手当だ。……母さんと<u>妹</u>が、それで食ってる」【声が小さくなる。メモ：「**家族を手当で食べさせている**」（太字＝確か）】 |
| ②「その手当がないと、何が困るの？」（問いかけ） | 同上の答え。ただし開1のときに聞くと「お前には関係ない」【かわされるだけ】 |
| ③「……本当は、戦いたくないんじゃない？」（早すぎるラベル） | 「なんだと！」【苛+2。拳を握る。※開3のあとなら、同じせりふで「……怖いさ。スライム二匹半の勇者だからな」と打ち明ける】 |
| ④（🔍懐の手紙を見たあと）「その手紙、大事そうだね」 | 「……妹からだ。『おにいちゃん、むりしないで』だとさ」【開+1。照れくさそうに笑う】 |
| ⑤「……」（黙って待つ） | 「……俺しか、いないんだよ。稼げるのは」【開2→3。沈黙のあとの本音】 |

### 9.4 まとめ

メモに「証」「協会」「家族」がそろうと、選択肢に**まとめのせりふ**が出る。

| トトのまとめ | レオンの反応 |
|---|---|
| 「手ぶらじゃ帰れないんだ。妹さんたちのために。……魔王に勝つかどうかより、『戦ってきた』って証がいる」 | 「…………そうなんだよ」【肩の力が抜け、吹き出しが柔らかい色に。開3・苛0。メモが一行にまとまる：「妹たちを食べさせるために、手ぶらでは帰れない」】 |
| （「名を上げたい」というメモが残ったまま）「名も上げたいし、家族も食べさせたい。だから証がいる」 | 「まあ……そんなとこだ」【絵は変わらない。気のない同意】 |

### 9.5 一緒に考える → 提案 → 反論 → 調整（「そうなんだよ」のあと）

| トトの返事 | レオンの反応 |
|---|---|
| ①「協会が信じる証って、どんなもの？」（問いかけ） | 「……見た者がいるとか。魔王の持ち物とか」【レオン自身が条件を出す】 |
| ②「魔王様のサイン入りの書状なら、頼めるかもしれない」 | 「紙切れ一枚じゃ、協会は……」【反論】→ ①で本人が出した条件（見た者）を足す案「罠課が、見物人の前で一騎打ちの舞台を作る」が次の選択肢に出る |
| ③「勇者が魔王の城で働くなんて、ありえない……かな？」（「いいえ」と言える質問。たね「家族」が開いているときだけ出る） | 「……ありえない、とは言わない。何の話だ」【身を乗り出す】 |

③のあと：

> **トト**：「城でね、『勇者役』を探してるんだ。毎日お客さんの前で派手に戦って、派手に負ける。給金も出るよ」
> **レオン**：「……でも、俺が魔王の城で働いてるなんて知れたら、勇者の<u>名</u>が……」【反論。目をそらす】

| トトの返事 | レオンの反応 |
|---|---|
| ①「勇者でいられなくなるのが、怖いんだね」（ラベル） | 「……ああ。妹には、勇者の兄貴でいたい」【条件がはっきりする】 |
| ②「名前なんて、気にしなくていいよ」 | 「お前にはわからん！」【苛+1。案が遠のく】 |

①のあと、選択肢に**手直しした案**が出る：

> **トト**：「肩書きは『勇者』のまま。魔王様に、『勇者レオン、当城にて見事な戦いぶり』って書状を書いてもらおう」
> **レオン**：「…………それなら、妹に胸を張れる」【合意 → 結末「勇者、就職する」】

### 9.6 途中でやめる道（いつでも）
- **👑 魔王様に通す**：v1 と同じく、レオンは三歩目で転ぶ。評判が下がり、協会がもっと強い勇者を送る。
- **🚪 お引き取り願う**：
  - 開2以上のとき：「……そうか。妹に、なんて言えばいいんだろうな」としょんぼり帰る。
  - 開0〜1のとき：「帰れるか！」と魔王の間に乗り込む。
