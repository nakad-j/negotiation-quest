- 3案は、ジャンル・雰囲気・交渉の形がはっきり違うものを選びました。どれも「誰もが知っている型」の上に「意外な視点」を1つだけ置いています。

## 0. 3案に共通する考え方

### 0.1 確定していること【確定】
- 娯楽が第一。学びは遊んだ結果として身につく。
- 視覚で伝える。文章の選択肢を並べない。
- Save the Cat! の15ビートを物語の土台にする。
- 物語・人物・舞台は「三日の勅命」から引き継がない。

### 0.2 3案で共通して提案すること【推奨】
- **交渉の相手は「表情を持った人」として画面の中心にいる**。数値のゲージではなく、顔・視線・手元・姿勢で反応を見せる。
- **提案は「物を卓に置く」操作で行う**。言葉を選ぶのではなく、品物・書類・人を、卓や相手の前に動かす。
- **相手は1人ではない**。複数の人物が同じ場にいて、それぞれ違うものを欲しがっている。誰に話しかけるか、誰を味方にするかが選択になる。
- **主人公には欠点がある**。その欠点が下手な交渉の癖として表れ、物語を通して直っていく。これが学びの芯になる。

## コンセプトA「魔王城の交渉係」

> 勇者と魔王の戦争は、八百長だった。その台本を回していたのは、あなただ。

### ジャンルと舞台
- ファンタジー・コメディ。勇者が攻めてくる魔王城の内側が舞台。
- 毎週のように勇者一行がやって来る。城の「渉外課」で働く小鬼の主人公は、勇者たちと**戦わずに話をつけて帰ってもらう**のが仕事。

### 主人公
- **トト**：魔王城の渉外課に勤める、小鬼の新米職員。気が弱く、相手を怒らせるのが何より怖い。
- **欲しいもの**：課長に昇進して、故郷の母に仕送りを増やすこと。
- **欠点**：その場を丸く収めるために、誰にでも「はい」と言い、嘘で取り繕う。自分の本当の望みを口にできない。
- **変化**：取り繕う交渉から、本当の利害を卓に出して作る交渉へ。

### 中心となる対立
- **表の対立**：勇者 対 魔王城。主人公は、勇者が城を荒らさずに帰るよう取引する（宝箱を1つ渡す、「魔王の角（偽物）」を持たせる、など）。
- **ミッドポイントで明かされる裏**：魔王と人間の王は、裏で**戦争を演じる契約**を結んでいた。王は「魔王の脅威」を理由に税を集め、魔王は城の仕事と名声を保つ。主人公の仕事は、その台本を回すことだった。
- **崩れるきっかけ**：台本を知らない本気の若い勇者（**リーナ**）が現れる。リーナの村は「対魔王税」で潰れかけている。八百長を続ければ村が潰れ、八百長をやめれば城の仲間が職を失い、本当の戦争が始まるかもしれない。
- **クライマックス**：魔王・王・勇者の三者を、初めて同じ卓につかせる。

### 主要人物と利害（概略）

| 人物 | 欲しいもの | 恐れているもの | 対立する利害 |
|---|---|---|---|
| トト（主人公） | 昇進、仕送り | 誰かに嫌われること | 仲間を守ること ⇔ リーナの村 |
| 老魔王ガルザ | 静かに引退して、盆栽を育てたい | 「腰抜け」と笑われること、部下が路頭に迷うこと | 引退したい ⇔ 戦争をやめると城が潰れる |
| 人間の王 | 税と王座 | 魔王がいなくなり、民の不満が自分に向くこと | 戦争の継続 |
| 勇者リーナ | 村を救うこと | 何も変えられないまま帰ること | 魔王を倒したい（立場） ⇔ 村を救いたい（利害） |
| 勇者一行の仲間 | 戦士は名声、僧侶は無事に帰ること、盗賊は宝 | それぞれ違う | 一行の中でも意見が割れる |

### なぜ「知っているのに新しい」のか
- **知っている型**：勇者が魔王を倒しに行く王道RPG。企画書の「自宅→王→仲間→魔王」の骨格をそのまま裏側から見ている。
- **新しい視点**：主人公は攻められる側の中間管理職。「戦い」は実は「商談」で、魔王と王はつるんでいる。

### 交渉が物語を動かす仕組み
- 毎回の勇者一行の来訪がそのまま交渉の場面。一行は3〜4人で、それぞれの欲しいものが違う。**一行を割る／まとめる**こと自体が遊びになる。
- 交渉の結果が城に残る。勇者に宝を多く渡せば城の財政が苦しくなり、渡さなければ本気の戦闘になって仲間が傷つく。
- 後半は相手が「勇者」から「魔王」「王」へと格上げされていく。クライマックスでは三者交渉になる。
- **代替案（BATNA）が物語の中に自然にある**：交渉が決裂すれば戦闘になる。その怖さ（城の仲間が傷つく）が、交渉を続ける動機になる。

### 象徴的な1場面（画面の例）

```
 ┌───────────────────────────────────────────┐
 │   [戦士]😠      [勇者]😐      [僧侶]😟     [盗賊]👀→宝箱 │
 │  ─────────────── 交 渉 卓 ───────────────  │
 │      📦宝箱      🦴偽の角      🗺抜け道の地図      │
 │                                           │
 │              [トト]😰                        │
 │   手元：🍞 💰 📜 🗝                            │
 └───────────────────────────────────────────┘
```
- 盗賊の視線は宝箱から離れない。僧侶は出口のほうをちらちら見る。戦士は腕を組んでいる。
- 「抜け道の地図」を僧侶の前に滑らせると、僧侶の表情がゆるむ。勇者は僧侶の顔を見て、迷い始める。
- 文章を一行も読まなくても、誰が何を欲しがっているかが読める。

### なぜ楽しいか
- 設定だけで笑える。毎回違う勇者一行（名声狂いの騎士団、遠足気分の学生勇者、値切り上手の商人勇者）が、そのまま新しいパズルになる。
- 「ミッドポイントで世界の見え方が反転する」快感がある。それまで自分がやってきた交渉の意味が変わる。
- 失敗しても楽しい。決裂すれば、城の仲間が慌てて戦うドタバタになる。

### リスク
- 「魔王側が主人公」「魔王は実はいい人」はライトノベルなどでよく使われる型で、目新しさが薄れる恐れがある。**八百長と中間管理職**という切り口で差別化する必要がある。
- コメディの調子が強すぎると、後半の重さ（村が潰れる）が浮く。
- 登場人物が多く、表情差分の絵の量が増える。

## コンセプトB「ひかりの言葉」

> 異星人は、攻めてきたのではなかった。基地の照明に、ずっと話しかけていたのだ。

### ジャンルと舞台
- SF・ヒューマンドラマ。辺境の惑星にある小さな採掘基地。
- 基地の周りに、光の模様で話す異星生物「ルミ」が現れるようになった。基地では、ルミの群れが設備を壊していると考えられている。

### 主人公
- **ソラ**：基地の整備士見習い（17歳）。母は基地の管理官。人と話すより機械をいじるほうが好き。
- **欲しいもの**：この星を出て、地球の工学校に行くこと。
- **欠点**：相手の話を最後まで聞かず、自分の考えで先回りする（機械なら直せるが、人はそうはいかない）。
- **変化**：「分かったつもり」で動く人から、相手の意図を確かめてから動く人へ。

### 中心となる対立
- **表の対立**：基地 対 ルミ。ルミは夜ごとに照明やアンテナを壊していく。本社は基地の撤退か、ルミの駆除かを迫る。
- **ひねり**：ルミは照明の点滅を「言葉」だと思っていた。基地の自動照明は、意味のない「挑発」を何か月も繰り返していた。**誤解の原因は人間の機械だった**。
- **ミッドポイント**：ソラが手持ちのライトでルミと「会話」できることに気づく。同時に、基地の採掘場がルミの産卵地の真上にあると分かる。
- **クライマックス**：駆除部隊の到着前に、ルミの長老と基地の母、本社の代理人の三者の間を、ソラが光と言葉で「通訳」する。

### 主要人物と利害（概略）

| 人物 | 欲しいもの | 恐れているもの |
|---|---|---|
| ソラ | 星を出ること | 母に失望されること |
| 母（管理官ユウ） | 基地の仲間の雇用と安全 | 本社に切り捨てられること |
| ルミの長老 | 産卵の季節に巣へ戻ること | 卵が潰されること |
| 本社の代理人 | 採掘量の数字 | 自分の責任になる事故 |
| 古株の採掘工ゲン | 年金まであと1年働くこと | 基地の閉鎖 |

### なぜ「知っているのに新しい」のか
- **知っている型**：ファーストコンタクト、少年と異生物の友情、「本当の侵略者は人間だった」。
- **新しい視点**：争いの原因が悪意ではなく、自動化された機械の「意味のない言葉」だった。交渉人は、人間と異星人のあいだに立つ機械オタク。

### 交渉が物語を動かす仕組み
- **相手の意図を読むことが、文字どおり視覚的な遊びになる**。ルミの感情は色と形と動きで表れる。プレイヤーは観察して「この色は警戒」「この形は欲しい」と自分で読み解いていく。
- 人間側の交渉（母、本社、採掘工）は普通の会話で行う。ルミとの交渉と対になり、「人間の表情も、実はルミの光と同じように読める」と気づかせる。

### 象徴的な1場面（画面の例）

```
 ┌──────────────────────────────────────┐
 │        🟣🟣  ルミの長老：紫が渦を巻く            │
 │       ／  ＼                                 │
 │   (◯赤)(◯青)(◯黄)  ←ソラのライト：色を選んで光らせる │
 │                                              │
 │   地面：⛏採掘機   🥚巣                         │
 │   [母]😠 無線「ソラ、戻りなさい」                  │
 └──────────────────────────────────────┘
```
- 採掘機をゆっくり巣から離すと、長老の紫がほどけて青くなる。

### なぜ楽しいか
- 「言葉の通じない相手を観察して理解する」ことが、それだけで新鮮で美しい。
- 誤解が解ける瞬間に強いカタルシスがある。
- 絵は抽象的な光の表現が中心なので、少人数でも雰囲気を出しやすい。

### リスク
- **交渉より「言語の解読パズル」が主役になりやすい**。異星語を読み解く系のゲームはすでにジャンルとしてあり、その中に埋もれる恐れがある。
- 異星人との交渉で学んだことが、人間どうしの交渉に結び付きにくい。
- 雰囲気が静かで、ユーモアや派手さに欠ける。Steam でのつかみが弱い。

## コンセプトC「なつやすみ わらしべ交渉」

> ビー玉1個から、町の夏祭りを取り戻す。最後に交換するのは、物ではなかった。

### ジャンルと舞台
- 現代日本・ひと夏の冒険。海辺の小さな町。
- 毎年の夏祭りが、町内会長の一声で中止になった。祭りまであと7日。

### 主人公
- **ハル**：小学5年生。夏の終わりに、この町から引っ越すことが決まっている。
- **欲しいもの**：最後の夏祭りで、親友と花火を見ること。
- **欠点**：欲しいものがあると、相手の都合を考えずに押し切ろうとする（駄々をこねる）。
- **変化**：「欲しい」と押す子どもから、「相手は何に困っているか」を聞ける子どもへ。

### 中心となる対立
- **表の対立**：子ども 対 祭りを中止した大人たち。
- **遊びの骨格**：昔話「わらしべ長者」。ハルはビー玉1個から始め、町の人と交換と頼みごとを重ねて、会場・花火・屋台・踊り手を集めていく。
- **ミッドポイント**：中止の本当の理由が分かる。町は借金を返すために、神社の裏山を業者に売ろうとしている。祭りの会場がなくなる。そして、**その売却を担当している市役所の職員は、ハルの母だった**。
- **クライマックス**：最後の交渉の相手は、自分の母。物ではなく、ハル自身の本音（引っ越したくない）を卓に出す。

### 主要人物と利害（概略）

| 人物 | 欲しいもの | 恐れているもの |
|---|---|---|
| ハル | 最後の祭り | 親友に忘れられること |
| 母 | 仕事をやり遂げ、ハルとの新しい生活を始めること | ハルを悲しませること |
| 町内会長の老人 | 町の存続 | 自分の代で町を終わらせること |
| 駄菓子屋のおばあちゃん | 店を誰かに継いでほしい | 一人になること |
| 業者の若い担当者 | 契約を取ること | 地元に嫌われること（実はこの町の出身） |

### なぜ「知っているのに新しい」のか
- **知っている型**：わらしべ長者、夏休みの冒険、子どもが大人を動かす物語。
- **新しい視点**：わらしべ長者を「物の交換」ではなく「相手によって物の価値が違う」ことを使う交渉として描く。最後の相手は悪役ではなく家族。

### 交渉が物語を動かす仕組み
- **同じ物でも、人によって価値が違う**。それが遊びの中心になる。駄菓子屋のおばあちゃんにはただのビー玉が、鉄道好きの男の子には宝物になる。
- 交換の連鎖がそのまま町の人間関係の地図になる。交渉が終わるたびに、町の地図に「仲間」が増えていく。
- 交渉の題材（おこづかい、門限、宿題、場所の貸し借り）が身近なので、学んだことがそのまま日常で使える。

### 象徴的な1場面（画面の例）

```
 ┌──────────────────────────────────────┐
 │   [鉄道少年]😐  頭の上：🚂💭                      │
 │  ──────── 縁 側 ────────                      │
 │      ハルが置いた：🔵ビー玉                         │
 │      相手が置いた：🎟花火大会の古いポスター              │
 │                                              │
 │   ハルの手元：🔵 🍬 📷 🐚                          │
 └──────────────────────────────────────┘
```
- 「📷（古いカメラ）」を手に取ると、少年の目が見開く。でも、ハルはそれが祖父の形見だと知っている。

### なぜ楽しいか
- 誰にでもすぐ分かる。子どもも大人も遊べる。
- 物の交換は、それだけで視覚的で手触りがある。
- 夏の終わりの切なさ、という強い感情の芯がある。

### リスク
- **わらしべの交換が「この人にはこの物」というお使いの連鎖になりやすい**（v1 の「情報と正解の1対1」と同じ罠）。値段を交渉する余地、断られる余地を意識して設計する必要がある。
- 規模が小さく派手さがないため、Steam の有料版としての訴求が弱い。
- 2〜4時間の長さを、町の中だけで支えられるか。

## 推奨【推奨】

### コンセプトA「魔王城の交渉係」を推奨します

**理由**
1. **交渉が「仕事」として物語の中心にある**。交渉する理由を説明する必要がない。主人公は交渉係なので、毎回の来訪がそのまま遊びの場面になる。
2. **多人数の交渉が自然に起きる**。勇者一行の中で意見が割れる、魔王と王の利害が裏でつながっている、という構図は、「立場と利害の違い」「連携」「代替案」をクイズにせず、遊びとして体験させられる。
3. **ミッドポイントの反転が強い**。前半の交渉（勇者を丸め込む）の意味が後半で変わり、主人公の欠点（取り繕う）と物語のテーマ（本当の利害を卓に出す）が重なる。
4. **企画書との連続性がある**。「魔王に向き合うRPG」という企画書の骨格を捨てずに、新しい視点で生かせる。Steam で「戦わないRPG」として説明しやすい。

### トレードオフ（Aを選ぶことで失うもの）
- **Cの身近さと切なさ**。学びが日常に移しやすいのはCです。Aの交渉は誇張されたコメディなので、振り返りの工夫が必要になります。
- **Bの視覚的な新しさ**。「相手の感情を色で読む」発想は、Aにも部分的に取り込めます（例：魔物は感情で体の色が変わる種族にする）。
- **Aの使い古された型の危険**。「魔王側の主人公」は珍しくありません。「八百長の戦争」「中間管理職の小鬼」という切り口を、物語の最初の10分ではっきり見せる必要があります。

### 取り込みたい他案の要素【推奨】
- Cから：**同じ品物でも相手によって価値が違う**という仕組み。Aの交渉卓に置く品物の価値を、勇者一行の一人ひとりで変える。
- Bから：**感情が色や形で見える種族**。魔物の仲間や魔王の感情表現に使い、表情差分の絵の量を減らしつつ、読みやすさを上げる。
