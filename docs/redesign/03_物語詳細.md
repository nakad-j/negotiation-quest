## 0. この物語の芯

### 0.1 ひとことで
> **嘘で平和を回していた小鬼が、嘘で回っていた世界の真ん中で、初めて本当のことを卓に出す話。**

### 0.2 テーマ【確定】
- **表のテーマ**：「はい」で守れる平和は、ばれるまでの平和でしかない。
- **裏のテーマ**：本当の利害を出し合えば、敵どうしでも「両方が得をする形」が作れる。ただし、正直になるのは交渉の終わりではなく、**始まり**にすぎない。

トトの欠点（誰にでも「はい」と言い、嘘で取り繕う）は、そのまま世界の仕組み（八百長の戦争）の縮図になっています。そして**王エドモンドもまた、30年間「はい」と言い続けてきた人物**です。トトは物語の後半で、自分の未来の姿を王の中に見ます。

### 0.3 Save the Cat! のジャンル【確定】
- 主筋：**「組織の中で」（Institutionalized）**。組織に属する個人が、組織のやり方に従うか、壊すか、変えるかを選ぶ型。
- 副筋：**「相棒もの」（Buddy Love）**。正直すぎる勇者と、嘘が上手すぎる小鬼。

## 1. 世界（必要最小限）

- **人間の王国**と**魔王領**。30年前、両者は本当の戦争をした。魔王領の畑は焼けて痩せ、王国の辺境は戦場になって、北の谷を魔王領に奪われた。
- 今は、勇者が魔王城に挑み、魔王が退ける、ということが毎年繰り返されている。王国は**対魔王税**を集めて勇者を送り出す。
- 魔王城には**渉外課**がある。勇者一行と裏で取引して、宝箱を持たせて帰ってもらうのが仕事。
- 勇者のあいだでは「魔王城は話せば通してくれる」という噂が、半ば公然の裏ルールになっている。人間も魔物も、これを「下っ端どうしの、ずる賢い現場の知恵」だと思っている。

**プレイヤーが最初に知るのはここまで。**

## 3. 八百長の真相と、その経済・政治

### 3.1 何があったのか
1. 30年前の戦争で、ガルザは息子を、エドモンドは兄（先王）を亡くした。急に王座についた若いエドモンドと、ガルザは、ひそかに会って和平を結んだ。
2. だが、どちらの民も和平を受け入れなかった。和平を公表すれば2人とも王座を追われ、強硬派が戦争を再開する。
3. そこで2人は、**戦争を続けているふりをする**ことにした。勇者が挑み、魔王が退ける。誰も死なない。
4. 魔王領は畑を失い、魔物たちを自力では食べさせられない。しかも戦争中という建前のために、人間との交易もできない。エドモンドは対魔王税の大半を、ひそかに魔王領へ送った。魔物たちが飢えて人間の村を襲わないための、**平和の費用**だった。

### 3.2 なぜ辺境の村に負担が集中したのか【確定：レビュー指摘3】

30年前に出された**「討魔の勅令」**が、税の仕組みを決めています。

| 条文（要旨） | 30年前の理由 | 30年後の結果 |
|---|---|---|
| **第一条**：魔王討伐のため、対魔王税を課す。**村ごとの定額**とする | 戦後の混乱で戸籍が失われ、人数で数えられなかった | 辺境は「戦場に近い」という評判で若者が都へ出ていき、人口が半分になった。村ごとの定額なので、**一人あたりの負担は倍になった** |
| **第二条**：**王都騎士団を維持する諸侯は、税を免除する** | 兄を亡くして急に王座についたエドモンドには、都の貴族とその騎士団の支持が必要だった。免除はその見返りだった | 都の貴族は30年間、一銭も払っていない。王都の周りの村々も貴族の領地なので免除されている |
| **第三条**：**教会が魔王の死を認めた日に、税は終わる** | 税を「一時的なもの」と見せて、民に受け入れさせるため | 平和のために税が必要なのに、教会の一言で税が自動的に終わる。**30年後の罠になる** |
| **第四条**：**魔王亡き後、奪われた旧領は旧主に返る** | 辺境の諸侯に戦後の希望を与えるため | 北の谷（今は魔物の集落）を、ハーゲンが取り戻す権利。**王の許可なしで発効する** |

**エドモンドは10年前に一度、第二条の撤廃を試みた**。都の貴族は「では騎士団を引き揚げる」と応じ、王都の守りがなくなることを恐れたエドモンドは引き下がった。それ以来、辺境の負担が増えていくのを知りながら、手を打てずにいる。

**魔王城の予算が削られた理由**：辺境の村が税を払いきれなくなり、魔王領への仕送りが毎年減っている。ヴェラが「今期は予算が削られた」と言うのはこのため（③の伏線）。

### 3.3 エドモンドの政治的ジレンマ【確定：レビュー指摘1】

ミッドポイントの後、教会が「勇者リーナ、魔王を討つ」と公に認めます（⑩）。このとき、エドモンドがどう動いても問題が起きます。

| エドモンドの選択 | 何が起きるか |
|---|---|
| **肯定する**（魔王は討たれた） | 第三条により税が終わる。魔王領への仕送りが止まり、魔物たちは冬を越せない。第四条により、ハーゲンは北の谷の奪還に動く。北の谷の魔物たちは追い出される |
| **否定する**（魔王は生きている） | 「なぜ王がそれを知っているのか」と問われる。説明すれば八百長がばれる。説明しなければ、教会が認めた英雄の手柄を、王が税のために握り潰したように見える。辺境は納税を拒み、ハーゲンは「では自分の手で魔王を討つ」と兵を挙げる |
| **保留する**（調べさせる）——**実際にエドモンドが選ぶ道** | ハーゲンには「少し待て」、都の貴族には「何も変わらない」、ガルザには（商人の連絡網で）「持ちこたえろ」と言う。**全員に「はい」と言う**。しかし第四条は王の許可なしで発効するので、ハーゲンは教会の認定だけを根拠に、兵を北の谷へ向ける |

**エドモンドが止められない理由**：討伐軍を止める法的な手段は、教会が認定を取り消すことしかない。そして認定の根拠は、**ミントの報告書**と、**リーナが持ち帰った角**です。

**トトとエドモンドの重なり**：エドモンドの「保留」は、トトの「はい」と同じ形をしている。全員を少しずつ満足させて、決断を先送りする。トトは⑪で、そうしたエドモンドの姿の中に、30年後の自分を見る。

### 3.4 角の意味【確定：レビュー指摘2】

角は「魔王を討った証」ではありません。**人間と魔物とで、意味が違う品**です。

| 誰にとって | 角の意味 |
|---|---|
| **人間の慣わし** | 「**角折りの功**」。魔王の角を折った勇者は、王に謁見して**褒賞を一つ願い出る**権利を得る。討伐の証ではない（魔王が死んだことにはならない） |
| **魔物の慣わし** | 角を折られた魔王は、**玉座を降りる**のが古い掟。死ぬわけではない |

**トトの計画（⑥）**：ガルザは毎年、角が生え変わる。古い角を付け直して、リーナに「折らせる」。
- リーナは「角折りの功」で王に謁見し、褒賞としてカヤ村の免税を願い出られる。税の撤廃ではない。**王との交渉を始める口実**にすぎない。トトも、王が願いを聞き入れるかどうかは分からない。
- ガルザは、魔物の掟に従って玉座を降り、引退できる。
- 魔王は死なないので、税の仕組み（そして城の財源）には影響しない——**はずだった**。

**計画が狂う原因**：ミントの報告書。ミントは教会に「聖なる勝利」を報告したい。トトはミントの頼みに「はい」と言い、ゴーレムの偽の書類づくりを手伝わせ、報告書の言い回しに口を出さなかった。ミントは報告書を「魔王の角を折った」から「**魔王を討ち取った**」に盛る。さらにガルザが掟どおり玉座から姿を消したため、「魔王はもういない」という話に信憑性が生まれる。教会はこれを根拠に、魔王の死を認めてしまう。

→ **トトの「ミントへのはい」が、第三条と第四条の引き金を引く。**

### 第1幕（約20%）

#### ① オープニング・イメージ
魔王城の玉座の間。勇者一行が突入し、派手な戦闘が始まる。炎、雷、崩れる柱。
——カメラが引くと、柱は張りぼてで、炎は罠課の職人が袖から送っている。舞台裏ではトトが帳面を手に、魔物たちに合図を出している（「あと三つ数えたら倒れてください」）。
一行は宝箱を抱えて満足げに帰っていく。トトは深々と頭を下げる。「またのお越しを」。

その奥で、ドグマ将軍が一人だけ本気で斧を振るい、空振りし、「なぜ誰も本気でやらんのだ！」と叫んでいる。

#### ② テーマの提示
到着したばかりのリーナが、取引を持ちかけてきたトトに言う。
> 「あなた、さっきから全部『はい』だね。本当は何が欲しいの？」

トトは答えられない。

#### ③ セットアップ
- **小さな勇者一行の来訪（1回）**【確定】：①の一行。トトの普段の仕事ぶりを体験させる。
- **ヴェラ課長**：「今期は予算が削られた。宝箱を減らしなさい。でも勇者は満足させて」。トトは「はい」と言う。
- **ドグマ将軍**：「次の勇者は俺に回せ」。トトは「はい、検討します」と言う。
- **老魔王ガルザ**：盆栽の手入れに呼び、こっそり頼む。「わしが穏やかに引退できる方法を探してくれんか」。トトは「はい」と言う。
- **母の手紙**：仕送りが頼り。
- **昇進の機会**：ヴェラ「次の大物勇者を無事に帰らせたら、あなたを課長補佐に推す」。

**停滞は死**：予算は減るのに、勇者は満足させろと言われる。いつか取引が成り立たなくなる。

#### ④ きっかけ
**リーナの一行**が来る。リーナは宝箱を断る。
> 「魔王を倒しに来たの。宝は要らない」

ボルドは頭を抱え、ミントは「討伐の形さえあれば」と小声で言い、ピコは「いいね、これは歌になる」と目を輝かせる。4人とも違うことを言っている。

#### ⑤ 迷い
規則では、取引に応じない一行はドグマの軍に回す（本気の戦闘になる）。
- トトはヴェラに「交渉は順調です」と**最初の大きな嘘**をつく。
- リーナの事情を聞く。カヤ村は税で潰れかけている。辺境伯ハーゲンはいつも「魔王さえ倒せば」と言っていた。
- トトは、自分の母とリーナの村を重ねる。

#### ⑥ 第2幕への突入
**トトが自分で計画を立てる**（§3.4）。
> 「角を折れば、王様に一つだけ願いを言える。村のことを、直接王様に頼めます」

ガルザは計画を聞いて目を細める。「角を折られた魔王は玉座を降りる。……掟じゃからの」。引退の口実になる。
トトの昇進にもなる。全員の望みが叶う計画に見える。

ただし、トトは同時に嘘を重ねる。
- **リーナに**：「角を折るのは、あなた自身の力です」。実際には、ガルザが付け直した古い角を、折れるように細工して差し出す。正直なリーナは、芝居だと知れば引き受けないから。
- **ヴェラに**：「普段どおり、宝箱で帰らせます」。
- **ドグマに**：「勇者との本気の決闘を手配します」。城の中で一行を動かすあいだ、ドグマを遠ざけるため。

### 第2幕前半（約25%）

#### ⑦ Bストーリー
**トトとリーナの相棒関係。**
- リーナは嘘がつけない。トトの「また今度ぜひ」を真に受けて、本当に「今度」の予定を入れてくる。
- トトは気づく。リーナが「魔王を倒す」ことにこだわるのは、それしか村を救う方法を知らないからだ。**立場と利害は違う。**
- リーナは、トトが本当のことを言ったときだけ、まっすぐ信じてくれる。トトはそれに戸惑う。

#### ⑧ お楽しみ
**勇者一行が、魔王城でアルバイトとして働きながら、角を折る舞台を整える。**
- **食堂のコック**：人手が欲しい。料理上手なボルドは、城の待遇（年金つき）に本気で惹かれ始める。
- **罠課の職人**：自分の罠が一度も本気で使われたことがないのが悩み。リーナが本気で罠に挑むと、職人は感激する。
- **宝物庫番のゴーレム**：書類しか信じない。古い角を持ち出すには書類が要る。ミントの「報告書を盛る」才能が、偽の書類作りで役に立ってしまう。トトはミントに「はい、何でも書いてください」と言う（**⑩の引き金の伏線**）。
- **ピコ**は城のあちこちで「取材」をして、こっそり手紙を出している。

**老商人の来訪（王エドモンドの初登場）**【確定：U-S4】
- 年に一度、穀物の荷車を引いて城に来る老商人がいる。今年の荷は去年より少ない。ヴェラはトトに、量を増やす交渉を任せる。
- 老商人は「今年はこれが精一杯でな。畑の村が、もう払えんのじゃ」と言う。トトはいつもの調子で、相手を気遣う「はい」を重ねる。結局、量は増えず、次の約束だけが増える。
- 老商人は、食堂で働くリーナと話す。カヤ村の話を聞いて黙り込み、彼女の名前を二度聞き返す。
- その夜、老商人とガルザは盆栽を挟んで将棋を指す。トトは茶を運びながら、2人の会話を聞く。
  > 老商人「あと何年もつかのう」
  > ガルザ「わしの腰か、おぬしの畑か」
  > 老商人「……両方じゃ」
- ピコは老商人を見て、明らかに動揺する（ピコは老商人の正体を知っている）。
- 老商人は、角の計画が実行される前に城を去る。

**ドタバタ**：ヴェラの抜き打ち視察のたびに一行を隠す。ドグマには「決闘は来週の火曜に」「天気が良ければ」と言い逃れを重ねる。

**この区間では「はい」がいちばん効く**。嘘は楽で、上手くいき、褒められる。

#### ⑨ ミッドポイント（偽りの勝利 → 反転）
**偽りの勝利。** 玉座の間で「角折りの儀」が行われる。リーナの剣が角に触れると、角は見事に折れる。ガルザは大げさに倒れ（本当に腰を痛め）、掟どおり玉座を降りると宣言する。
リーナは角を掲げ、ピコは歌い、ミントは報告書を書く。一行は角を持って王都へ旅立つ。トトは初めて、自分の交渉に誇りを感じる。

**反転。** その夜、ヴェラが青ざめてトトを帳簿室に連れていく。ミントの報告書の写しが届いている。そこには「**魔王を討ち取った**」と書かれていた。
- ヴェラは城の財源を明かす。「本社からの仕送り」は、王国の対魔王税だった。教会が魔王の死を認めれば、討魔の勅令によって税が終わる。仕送りが止まれば、魔物たちは冬を越せない。
- ガルザが帳簿室に来て、すべてを話す（§3.1）。そして言う。
  > 「あの老商人が、エドモンド王じゃ。30年、二人でこの芝居を回してきた」
  > 「わしは疲れておった。おぬしの計画に乗れば、誰かがこの嘘を終わらせてくれると思ったんじゃ。……すまん」
- ヴェラも、王の正体までは知らなかった。

**状況がどう変わったか**
- 前半：「勇者を帰らせれば勝ち」という小さな交渉。
- 後半：「30年の平和を、嘘なしでどう着地させるか」という大きな交渉。

**ここでのトトの選択**：リーナに本当のことを知らせる手紙を書くか、「大丈夫、心配ない」と書くか【推奨：プレイヤーの選択】。どちらを選んでも⑩でリーナは真実を知るが、トトから聞いたか、他人から聞いたかで、⑫の再会の形が変わる。

### 第2幕後半（約25%）

#### ⑩ 迫り来る悪い奴ら
**悪い奴ら＝トトがこれまでに重ねた「はい」が、一度に返ってくる。**

| 返ってくる「はい」 | 何が起きるか |
|---|---|
| **ミントへの「何でも書いてください」** | 教会が報告書と角の届け出を根拠に、魔王の死を認める。討魔の勅令の第三条（税の終わり）と第四条（旧領の返還）が発効する |
| （その結果） | ハーゲンは第四条を根拠に、兵を北の谷へ向ける。エドモンドは「保留」を選ぶが、止められない（§3.3） |
| **ドグマへの「本気の決闘を手配します」** | 角折りの儀から外されていたドグマは、騙されていたことを知る。さらに帳簿室の話を立ち聞きし、30年の戦争がすべて芝居だったと知る。「俺の30年は何だったのか」。ドグマはガルザを玉座の間に閉じ込め、「北の谷を守る本当の戦争」のために魔物の強硬派を集める |
| **リーナへの「角を折るのは、あなた自身の力です」** | 王都の謁見の間で、エドモンドは角を見てすぐに気づく（城の棚で何度も見た、生え変わりの古い角だった）。人払いをして、エドモンドはリーナに「この角をどこで手に入れた」と問う。ピコが芝居の一部始終を明かす。エドモンドはリーナに正直に言う。「そなたの村を免除すれば、この冬、別の誰かが飢える」。リーナは、自分が芝居の駒だったこと、そして税が魔物たちの命綱だったことを知る |
| **ヴェラへの「普段どおりです」** | ヴェラはトトを渉外課から外す。昇進の話は消える。ヴェラ自身は城を守るため、ドグマの下で城の実務を回し続ける。「生き残るのが先よ」 |

**勇者一行の分裂**（それまでのトトの選択で形が変わる）
- ボルドは、城の待遇を約束されていれば城に残る。そうでなければ、報酬を持って去る。
- ミントは、自分の報告書が引き金を引いたと知って震える。トトとの関係次第で、報告書を撤回する覚悟を持つか、口をつぐむ。
- ピコは王のもとに残る。

**トトとリーナの決別**：城を追われたトトは、王都からカヤ村へ戻る途中のリーナに追いつく。リーナはトトを見ずに言う。
> 「私は、あなたの芝居の中で勇者をやっていたんだね」

#### ⑪ すべてを失って
- カヤ村の先の峠で、ハーゲンの辺境軍（大半は村の農民）と、ドグマの魔物の軍が向かい合う。北の谷の魔物の集落は、その真ん中にある。30年ぶりの本当の戦争まで、あと1日。
- 母から手紙が届く。小鬼の村の若者も、ドグマの軍に集められている。
- 王都からの使者が、エドモンドの言葉を伝えてくる。「双方、軽はずみな動きは控えよ」。誰も聞かない。トトは、30年間「はい」と言い続けてきた王の言葉が、もう誰にも届かないことを知る。
- **死の気配**【確定：誰も死なない。ただし危機の深刻さは失わない】：明日、農民と魔物の若者が、初めて本当に殺し合う。30年の「戦死者ゼロ」が、トトの計画のせいで終わろうとしている。
- トトは一人。課も、相棒も、魔王の信頼も、昇進も失った。

#### ⑫ 心の闇
トトは自分の「はい」を数え直す。すべての危機が、自分の約束から始まっていた。
- 誰もがっかりさせたくなくて「はい」と言った。その結果、全員をがっかりさせた。
- エドモンドの姿は、30年後の自分だった。
- 母の手紙の問いを思い出す。「あんたは本当は何がしたいの」。
- トトは初めて自分の望みを言葉にする。**昇進ではなく、誰も死なせないこと。そして、もう嘘をつかないこと。**

**物語の中でいちばん小さく、いちばん大事な交渉**：カヤ村でリーナに会う。トトは言い訳せずに、すべてを話す。芝居だったこと、自分の昇進のためでもあったこと、ミントの報告書を止めなかったこと。
> リーナ：「最初からそう言ってくれればよかった。……それなら、一緒に考えられたのに」

リーナは条件をつけて戻ってくる。「もう私に嘘をつかないこと。それと、私の村を、ちゃんと勘定に入れること」。

**正直に話すことは、交渉の始まりにすぎない**：リーナは許したのではない。トトを「一緒に考える相手」として、もう一度卓につかせただけ。

**プレイヤーの選択**：ここでトトがどこまで本当のことを話すかを選べる【推奨】。取り繕い続けた場合は §8.2 を参照。

### 第3幕（約30%）

#### ⑬ 第3幕への突入
**トトの計画**：明日の夜明け前に、峠で、全員を一つの卓につかせる。そのために、まず**言葉ではなく実物**で、ハーゲンに「魔物と組む価値」を見せる。

**カヤ村での実演**（トトの発案）
- カヤ村は若者が出ていき、壊れた水車も、流された橋も、直す人手がない。
- トトは、第2幕前半で正直に向き合った城の魔物たち（罠課の職人、ゴーレム、コック）に頼む。彼らは夜のうちに城を抜け出してきて、一晩で水車を直し、橋を架ける。コックとボルドは、村と魔物の両方に炊き出しをする。
- 朝、ハーゲンはそれを見る。憎んでいた魔物が、自分の村の水車を回している。
- ハーゲンはまだ納得しない。だが、卓に座ることには同意する。

**手を貸してくれるのは、トトが嘘で動かさなかった相手だけ。** 嘘で動かした相手は来ない（§6）。

その間に、リーナはピコを通じてエドモンドに、ミントは教会に、トトはヴェラを通じてガルザとドグマに、それぞれ卓への招きを届ける。

#### ⑭ フィナーレ

**1. 仲間を集める**
来る人はそれまでの選択で変わる。ボルド、ミント、ピコ、城の魔物たち、そしてヴェラ（ヴェラは「計算を確かめに来ただけ」と言って来る）。

**2. 計画の実行：両軍のあいだに卓を出す**
夜明け、両軍がにらみ合う峠の真ん中に、罠課の芝居の仕掛けが卓をせり上げる。**30年の八百長の道具を、初めて本当の交渉のために使う。**
ピコの歌が両軍に「卓がある」ことを告げ、ミントが教会の名で休戦の場を保証する。
エドモンドが来る。ガルザは、ドグマの監視つきで連れてこられる。

**3. 塔の上の驚き：卓が崩れかける**
トトは最初に、自分がしたことを認める。角の細工、ミントの報告書、ドグマへの嘘。
**これで誰かが心を動かして、告白を始めるわけではない。** トトの告白で得られるのは、「この小鬼は、自分に不利なことも言う」という**仲介役としての信用**だけ。
- ハーゲン：「それで？ お前が嘘つきだと分かっただけだ。なぜ30年、辺境だけが払ってきた」
- エドモンドは答えない。八百長を認めれば、都の貴族に王座を追われ、強硬派の時代になる。
- ガルザも答えない。認めれば、ドグマと魔物たちの30年の誇りを踏みにじる。
- ドグマ：「答えぬなら、ガルザの本物の首をもらう」
- ハーゲン：「答えぬなら、日の出とともに谷へ入る」

卓は崩れかける。

**4. 奥の手：一人ずつの利害を、取引として組み直す**
トトは卓を中断して、一人ずつと別々に話す。それぞれが「**何を恐れて黙っているのか**」を確かめ、その恐れを取り除く取引を組む。告白は、心変わりではなく**取引の対価**として出てくる。

| 相手 | 黙っている理由（恐れ） | トトが組む取引 |
|---|---|---|
| **エドモンド** | 都の貴族の支持を失えば、王座を追われる | **ハーゲンたち辺境の諸侯が、王を支持する**。辺境の支持があれば、都の貴族なしでも王座を保てる。ハーゲンが出す条件は「なぜ30年払わされたのか、本当のことを公に言うこと」と「第二条（貴族の免除）を撤廃すること」。エドモンドの告白は、辺境の支持を得るための対価になる |
| **ハーゲン** | 魔物と組めば領民に裏切り者と呼ばれる。谷を諦めれば父に顔向けできない | 告白と免除の撤廃に加えて、**辺境はただちに免税**。北の谷は返らないが、谷の魔物たちが**辺境の村で働き手になる**（⑬の実演が根拠）。交易の利益の一部を辺境に回す |
| **ガルザ** | 認めれば、ドグマと魔物たちの誇りが傷つく | ガルザが**ドグマに公に詫びる**こと、そして「なぜドグマにだけ本当のことを言わなかったのか」を話すことが条件。代わりに引退が認められ、魔物たちの生計は和平の取り決めで保証される |
| **ドグマ** | 自分の30年が無意味だったこと | ガルザが明かす理由：「本当の戦争になったとき、魔物たちがついていくのはおぬしだけじゃった。おぬしが本気でいてくれたから、この芝居は30年もった」。ドグマは**人間と魔物の合同の国境守備隊**の長になる。谷から辺境の村へ働きに出る魔物たちを、人間の強硬派から守る、初めての本物の任務 |
| **ミント** | 報告書を撤回すれば、教会での地位を失う | **教会が和平の保証人になる**。「聖なる勝利」より大きな「聖なる和平」を、ミントが教会に持ち帰る。報告書の撤回は、和平の証人としての最初の仕事になる。さらに、**死んだことになっている魔王は和平の条約に署名できない**ので、撤回なしでは和平が成り立たない |
| **ヴェラ** | 理想論の和平では、この冬、城が持たない | ヴェラは最後まで信じない。代わりに条件を出す。①冬越しの基金は**冬の前に前払い**すること。②魔物の働き手の賃金は**書面の契約**にすること。③交易が軌道に乗るまでの3年間、毎年見直すこと。これが満たされなければ、署名しない |

**5. 新しい計画の実行：合意**
一人ずつの取引がそろったところで、卓に戻る。エドモンドとガルザは、それぞれの取引の対価として、30年の八百長を公に認める。ピコが、その場で最初の一節を歌い始める。

### 4.1 合意の中身：各人物が譲るもの・得るもの・引き受けるもの【確定：レビュー指摘4】

| 人物 | 譲るもの | 得るもの | 引き受けるもの |
|---|---|---|---|
| **エドモンド** | 30年の秘密。都の貴族の支持（第二条の撤廃） | 辺境の諸侯の支持。「戦争を終わらせた王」という名 | 都の貴族との対立。30年騙してきたことへの非難 |
| **ガルザ** | 玉座。「無敗ではないが不死の魔王」という建前 | 引退と、盆栽の日々 | ドグマと魔物たちへの公の謝罪。30年の嘘の責任 |
| **ドグマ** | 本当の戦争と、復讐 | 真実と、自分の力が本当に役立つ任務 | 昨日まで敵だった人間と並んで、魔物の働き手を守る難しい仕事 |
| **ハーゲン** | 北の谷の奪還。魔物への憎しみを、少なくとも表には出さないこと | 辺境の免税、働き手、交易の利益の分け前、30年の真実 | 魔物を村に迎え入れることへの領民の反発 |
| **ヴェラ** | 慣れた仕組み（仕送りの予算） | 前払いの基金と書面の契約 | 新しい仕組みを城の実務として回すこと（城の新しい長として） |
| **ミント** | 「魔王を討った」という報告 | 和平の保証人としての教会の役目 | 報告書を盛ったことの告白 |
| **リーナ** | 「魔王を倒す勇者」という立場 | カヤ村の免税と、村の働き手 | ハーゲンと村人に、魔物と組む理由を説明すること |
| **トト** | 昇進、取り繕いの技術 | 誰も死なない明日 | 和平の取り決めの「交渉係」。全員が互いに正直でいるかを見張る役目 |

**誰もが何かを失っています。** 全員が満足する魔法の解決ではなく、全員が「戦争よりはこちらがいい」と判断できる取引です。交渉が決裂したときに誰がいちばん失うか（ハーゲンの村は戦場になり、魔物たちは冬に飢え、エドモンドは王座を失い、ガルザは首を失う）が、全員を卓にとどめます。

#### ⑮ ファイナル・イメージ
①と対になる場面。魔王城の玉座の間に、また人間の一行がやって来る。今度は勇者ではなく、商人や旅人。
トトは卓の向こうで、客の無茶な注文に初めて答える。
> 「それはできません。……その代わり、こういうのはどうでしょう」

城には人間と魔物が入り混じっている。ガルザは中庭で盆栽をいじり、ドグマは人間の兵と並んで門に立っている。ヴェラは帳簿を手に、まだ何かを疑っている。
母への手紙の最後の一行は、「僕が本当にしたいことは——」で始まる。

（どんな姿になっているかは、迎えた結末で変わる。§8）

## 5. 笑いの設計

| 源 | 例 |
|---|---|
| **性格** | ガルザの威厳と腰痛。ドグマだけが本気。ボルドの「この手の取引は3回目だ」。リーナが社交辞令を真に受ける。ヴェラが和平の卓に契約書の雛形を持ってくる |

## 6. プレイヤーの選択と結果（物語の水準で）

遊びの仕組みは Phase 4 で決めます。ここでは「物語の上で、どんな選択があり、何に影響するか」だけを定めます。

### 6.1 選択の種類

| 種類 | 物語の中の例 | 影響 |
|---|---|---|
| **誰に「はい」と言うか** | ヴェラ、ドグマ、ガルザ、ミント、老商人、一行の4人 | 前半は楽になる。⑩で返ってくる |
| **本当のことを言うか、取り繕うか** | リーナへの説明（⑥、⑨、⑫）、ドグマへの言い逃れ、ミントとの共犯 | 誰が⑬の実演と⑭の卓に来てくれるか |
| **一行の誰の望みを優先するか** | ボルドに城の仕事を約束する／ミントの報告書を手伝う／ピコに劇的な場面を約束する | ⑩の分裂の形、⑭の仲間 |
| **何に気づこうとするか** | 予算が減った理由、老商人とガルザの関係、ピコの手紙 | ミッドポイントの衝撃の大きさ。⑩の危機の一部を事前に和らげられる（例：ミントの報告書の言い回しを確かめておく） |
| **最後の合意の中身** | 誰の恐れを、どの取引で取り除くか | 結末（§8） |

### 6.2 トトの成長は選択に表れる
- **前半では「はい」がいちばん効く**。プレイヤーは自然に「はい」を重ねる。
- **⑩で、その請求書が一度に届く**。プレイヤーはトトと同時に、自分の選択の重さを知る。
- **⑫以降は、正直さが新しい力になる**。正直に向き合った相手だけが、手を貸してくれる。
- 前半で正直だったプレイヤーには、⑩の危機の一部が起きない（例：ミントが報告書を盛らない、ドグマの怒りが小さい）。その代わり、前半の交渉は難しくなる。
- **前半の「はい」を罰しすぎない**。どんな選び方をしても、⑫で立ち直る道は開いている。

## 7. 和平後の世界：魔物はどう生きていくのか【確定：レビュー指摘3、U-S2】

和平の中心は、**人間と魔物の公開の交易と共同事業**です。

### 7.1 なぜ戦争中は自立できなかったのか
- 魔王領の畑は30年前に焼かれ、魔物たちを養えるほどの作物が採れない。
- 魔物には腕のいい職人が多い（罠、建築、料理、芝居の仕掛け）。だが「戦争中」という建前のせいで、人間と交易できなかった。
- つまり**戦争の建前そのものが、魔物たちを仕送りに頼らせていた**。

### 7.2 和平後の生計（時間の順に）

| 時期 | 仕組み | 誰が払い、誰が得るか |
|---|---|---|
| **最初の冬**（すぐに） | **冬越しの基金**。第二条の撤廃で、都の貴族が初めて払う税を、この冬だけ魔王領の食糧に充てる。ヴェラの条件どおり、冬の前に前払い | 都の貴族が払う。辺境の村は即時免税 |
| **春から**（1年目） | **辺境の農地での雇用**。若者が去った辺境の村に、谷の魔物たちが働き手として出る。賃金は穀物で払う。ドグマの守備隊が、働き手を強硬派から守る | 辺境は人手を、魔物は食糧を得る。互いに相手が持たないものを持っている |
| **1〜3年目** | **職人仕事の交易**。罠課の技術は農具や錠前に、ゴーレムの力は橋や水路の工事に、コックの料理は街道の宿に | 魔物は収入を、人間は品物と工事を得る。交易の利益の一部は辺境に回る |
| **共同事業の例** | **勇者体験の城**。30年の八百長で磨かれた「派手で安全な戦い」の技術を使い、魔王城を人間の客に開く。入場料は城の収入になる | 八百長の技術が、隠れた費用から公の商売に変わる。①の張りぼての場面が伏線になる |
| **長い目で**（3年目以降） | **焼けた畑の共同の再生**。人間の農法と魔物の労働で、魔王領の畑を少しずつ取り戻す | 魔王領が自分で食べていけるようになる |

**ヴェラの見立て**：「最初の冬は基金で越せる。春の雇用は人間がちゃんと賃金を払えば回る。交易は3年は赤字よ」。現実派の彼女の計算が、和平の取り決めを具体的にする。

## 8. 結末【確定：U-S1 4つの結末を維持】

### 8.1 4つの結末

⑭で、どの取引がそろったかで結末が分かれます。

| 結末 | 成立する条件（物語の水準） | 合意の中身 | トトの姿 |
|---|---|---|---|
| **A 本当の和平** | §4.1 の取引が全員分そろう。⑬の実演が成功している。ミントが報告書を撤回する | 八百長を公表し、戦争の終わりを宣言する。第二条を撤廃し、§7.2 の交易と共同事業に移る | 正直な交渉人。⑮で「いいえ、その代わりに」と言えるトト |
| **B 新しい八百長** | ハーゲンかエドモンドの取引がそろわず、公表ができない。ヴェラが代わりに「秘密のまま仕組みを直す」案を出す | 公表しない。カヤ村を含む辺境の一部だけを免税にし、その穴を仕送りの減額で埋める。ドグマには「勇者を退けた」という形の勝利を与える。ドグマとハーゲンは騙されたまま | ヴェラの下で働き続けるトト。戦争は避けられたが、嘘が一段深くなった。ほろ苦い |
| **C 痛みのある和平** | 公表はできたが、誰か一人の恐れを取り除けなかった | 和平は成るが、一人が代償を払う。例：ドグマと和解できなければ、ドグマは反乱の罪で追放される。ハーゲンを説得しきれなければ、雇用の取り決めがなく、魔物の冬は基金だけに頼る。エドモンドの取引が弱ければ、エドモンドは責任を取って退位する | 正直にはなったが、全員を救うには力が足りなかったトト |
| **D 決裂** | 卓が崩れる | 小さな衝突が起きる。罠課の芝居の炎と煙で両軍が逃げ散り、死者は出ない。だが、平和は一から作り直しになる | 城を去り、母の村に帰るトト。⑮は小鬼の村での、小さな「いいえ」 |

### 8.2 最後まで嘘をつき続けた場合【確定：U-S7 を検討】

⑫でリーナに取り繕い、⑭でも嘘で取引をまとめようとした場合です。

- **トトは嘘が上手いので、取引はまとまる**。B「新しい八百長」に、より深い形でたどり着く。トトは新しい台本を書き、ドグマには偽の勝利を、ハーゲンには偽の約束を、エドモンドとガルザには「あと10年もつ」仕組みを渡す。
- **リーナは戻らない**。⑬の実演に来るのは、トトが嘘で動かさなかった少数の魔物だけ。
- **トトは昇進する**。物語の最初に欲しがっていたもの（昇進と仕送り）は手に入る。しかし、本当に必要だったもの（自分の望みを口にすること）は手に入らない。Save the Cat! で言う「欲しいものを得て、必要なものを失う」結末。
- **ファイナル・イメージ**：①とまったく同じ構図。舞台裏で帳面を手に、笑顔で「はい」と言うトト。違うのは、トトが課長補佐の腕章をつけていること。そして、母への手紙が書きかけのまま机に置かれていること。
- 嘘がうまくいかなければ、D「決裂」になる。

**扱い【推奨】**：独立した5つ目の結末にはせず、B の「暗い変奏」として扱う。4つの結末という枠は保ちつつ、「嘘をつき通した結果」がはっきり違う最後の場面で示される。

## 9. 因果の確認

```
討魔の勅令 第一条・第二条（村ごとの定額、貴族の免除）
  → 辺境の負担が増え、村が払えなくなる → 仕送りが減る → 城の予算削減 ③
予算削減＋ドグマ・ガルザ・ヴェラの頼み → トトは無理な約束を重ねる ③
リーナが取引を拒む ④ → トトの最初の大きな嘘 ⑤ → 角の計画と嘘 ⑥
老商人（王）の来訪：仕送りの減少、リーナとの出会い ⑧
ミントへの「何でも書いてください」⑧ → 報告書の「討ち取った」⑨
角折りの儀 ⑨ → ガルザが掟どおり玉座を降りる → 「魔王はもういない」に信憑性
報告書と角 → 教会が魔王の死を認める ⑩
  → 第三条：税が終わる → 仕送りが止まる → 魔物の冬が危うい
  → 第四条：ハーゲンが北の谷へ兵を向ける（王の許可は不要）
  → エドモンドは保留する（全員に「はい」）が、止められない
ドグマは儀式から外され、帳簿室の話を立ち聞きする → 真実を知り挙兵する ⑩
王が角に気づく、ピコが明かす → リーナが真実を知り、トトと決別する ⑩
両軍の対峙 ⑪ → トトが王の中に自分を見て、自分の望みを知る ⑫
→ リーナとの正直な交渉 ⑫ → カヤ村での実演 ⑬ → 峠の卓 ⑭
→ トトの告白は仲介役としての信用だけを生む → 卓が崩れかける
→ 一人ずつの恐れを取り除く取引 → 告白は取引の対価として出てくる → 合意 ⑭
```

### 9.1 確認した点
- **危機（⑩）はすべて、トトの選択から起きている**。ミントへの「はい」が勅令の引き金を引き、ドグマへの嘘が挙兵を、リーナへの嘘が決別を生む。
- **王が討伐軍を止められない理由が具体的になった**。第四条は王の許可なしで発効し、止める手段は教会の認定取り消しだけ。
- **王は前半に登場する**。老商人として、トトと直接交渉し、リーナと話し、ガルザと将棋を指す。
- **角は税撤廃の保証ではない**。王に謁見して願いを一つ言える口実にすぎない。その意味が人間と魔物とで違うことが、計画の前提になっている。
- **辺境だけが払ってきた理由が、勅令の条文で説明できる**。
- **和平後の生計が、時間の順に具体化された**。最初の冬の基金、春からの雇用、交易、共同事業。
- **クライマックスの告白は、心変わりではなく取引の対価として出てくる**。各人物の恐れと、それを取り除く取引が対になっている。
- フィナーレの解決に使うもの（芝居の仕掛け、教会の印、ピコの歌、城の魔物の技術）は、すべて第2幕前半で登場している。
