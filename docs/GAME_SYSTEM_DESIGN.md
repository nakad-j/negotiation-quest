## 1. 中心体験の定義

> **「王が言っていることと、本当に困っていることは違った。それに気づいたから、誰も思いつかなかった条件で合意できた」**

再設計依頼の中心体験（情報を集め、事情を理解し、新しい解決策を発見する）【依頼】を、王との謁見の1場面で言い換えるとこうなります。

### 1.1 この体験を象徴する場面

王は「三日のうちに北へ発て」と命じる。主人公は準備の時間が欲しいが、王は急いでいる。

- 情報がない場合：「では五日ください」と頼んで拒否される。結局「明朝出発」を受け入れることになる。
- 主人公は探りを入れる：「なぜそれほど急がれるのですか」
  王：「十日後に諸侯会議がある。それまでに北の様子を知らねばならん」
- **気づき**：王が欲しいのは主人公の「早い出発」ではなく、会議前の「情報」だ。
- 城の書記官から、伝書鳩なら北の砦から2日で届くと聞いていた。
- **提案**：「五日の準備をいただければ、砦に着いてから2日ごとに鳩で報告します」
- 王：「……それなら会議に間に合うな。よかろう」

プレイヤーは「急ぐ／急がない」という対立を、「出発の早さ」と「情報の早さ」に分けることで解きました。これが**利害と立場の違い**であり、**選択肢の拡張**です。振り返り画面でこの概念名が示されます【企画 §7】。

### 1.2 設計の柱

| 柱 | 意味 | 支える仕組み |
|---|---|---|
| P1 事情が見える | 相手の言葉や仕草の裏に、ゲーム的に実在する「利害」がある | 相手モデル（§3.5） |
| P2 気づきは組み合わせから | 手掛かり1つでは答えにならず、組み合わせると推測になる | 気づき（§3.2） |
| P3 解決策は組み立てる | 用意された答えを選ぶのではなく、部品を組んで提案する | 提案の組み立て（§3.4） |
| P4 反応から学ぶ | 断られても、その理由の手掛かりが得られる | 反応と理由（§3.6） |
| P5 正解は1つではない | 3つ以上の合意ルートがあり、それぞれ代償が違う | 2軸評価（§3.9）、シナリオ（§4） |

## 2. ゲームループ

### 2.1 全体の流れ

```
 探索（自宅・城）  →  謁見（王の要求と既定案を聞く）  →  交渉卓（ラウンド制）  →  合意書  →  振り返り
   手掛かりを集める       「表の要求」を知る             探る・提案する・反応を読む     結果      王の本音を知る
```

### 2.2 フェーズごとに、プレイヤーが考えること・選ぶこと・得る反応

| フェーズ | プレイヤーが考えること | 選ぶこと | 得られる反応 |
|---|---|---|---|
| 探索：自宅 | 旅に何が要りそうか | 家族・幼なじみと話す（制限なし） | 手掛かり（北の村の不安、紹介状という仕組み） |
| 探索：城 | 「謁見の刻まで、話せるのはあと2人」。誰の話が役に立ちそうか | 城内の4人のうち2人を選ぶ | 手掛かり。選ばなかった2人の情報は、今回は得られない |
| 謁見の冒頭 | 王は何を求めているのか。何も決まらなかったらどうなるのか | （選択なし。会話を読む） | 王の表の要求、大臣が示す**既定案**（決まらなかった場合の条件） |
| 交渉卓：探る | 王の言葉の裏に何があるのか。確かめてから動くか、賭けて動くか | 質問を1つ選ぶ（忍耐を1消費） | 王の答え → 手掛かりや気づきが増え、反応予測が見えるようになる |
| 交渉卓：提案 | 何を求め、何を差し出し、どんな形にするか。何を根拠に示すか | 部品を組み立てて提案する（忍耐を1消費） | 受諾／対案／保留／拒否と、その**理由の手掛かり** |
| 交渉卓：王の一手 | 王は次に何をしてきそうか | 王の対案や期限の念押しを、受けるか断るか | 合意書が埋まる、または心証が変わる |
| 合意 | これで十分か、まだ粘るか | いつ締めるかを決める | 合意書（旅の条件）と、物語としての結末 |
| 振り返り | 自分は何を見て、何を選んだか | （閲覧） | 王の本音、自分の判断3つ、あり得た別の合意、概念名 |

### 2.3 交渉卓の1ラウンド

1. **予兆**：王の様子が描写される（例：「王は窓の日差しに目をやった」）。理解している利害が多いほど、予兆の意味がUIに補足される。
2. **プレイヤーの行動**：「探る」「提案する」「人払いを願う」「締める」から1つ選ぶ。
3. **王の反応**：答え、または提案への反応（理由の手掛かり付き）。
4. **王の一手**：条件を満たしていれば発動する（対案、期限の念押しなど）。
5. **気づきの判定**：新しい手掛かりで推測が生まれたら、「ひらめき」として表示する。

## 3. システム詳細

### 3.1 手掛かり（Clue）

- 会話・探索・観察で得る事実。手帳に**カード**として並ぶ（企画書の「情報がカードになる」【企画 §5.2】を引き継ぐ）。
- 1枚の手掛かりは、次の4つの役割を**複数**持ち得る【提案】：

| 役割 | 例 |
|---|---|
| ①気づきの材料：ほかの手掛かりと組み合わさって推測を生む | 大臣のため息 ＋ 王の視線 → 「国庫が苦しいのでは」 |
| ②提案の部品を開く：新しい「求めるもの」「差し出すもの」が選べるようになる | 幼なじみの話 → 「商人への紹介状」 |
| ③根拠：提案に添えて示すと、王の受け止め方が変わる | 衛兵の話を示す → 騎士の同行を頼むときに王の面子が傷つかない |
| ④探りを開く：新しい質問ができるようになる | 倉番の話 → 「倉の具合はいかがですか」と聞ける |

- **鍵にしない工夫**：重要な部品や気づきには、2つ以上の入手経路を用意する（例：「倉の余剰物資」は、倉番から聞くか、人払いの後に王の本音として聞くか）。

### 3.2 気づき（推測）と確度

- 手掛かりが条件どおりにそろうと、王の**利害についての推測**が自動で生まれる（演出：「ひらめき」）【提案】。
- 推測には確度が2段階ある：
  - **推測**：そうかもしれない。反応予測は「▲？」のように方向だけ見える。
  - **確信**：王の口から確かめた。反応予測が影響の大きさと重要度まで見える。
- 推測から確信へ上げる方法：その利害に関わる質問をする、人払いをする、または提案への反応で理由がはっきり語られる。
- **ここに判断がある**：推測のまま提案するか（忍耐の節約）、確かめてから提案するか（安全）。これが「相手の事情を推測する」体験です（再設計依頼の体験2）。

【未決】U-S1：気づきを自動で生むか、プレイヤーが手掛かり同士をつなぐか。
- 【提案】は MVP では自動生成です。手動でつなぐ方式は「全組み合わせを試す作業」になりやすく、UI のコストも高いからです。その分、推測を確かめるかどうかの判断と、部品の組み立てで、プレイヤー自身の推論が求められるようにします。

### 3.3 交渉卓（ラウンド制）

| 要素 | 内容 |
|---|---|
| 王の忍耐 | 6。1つの行動で1減る。**拒否された提案はさらに1減る**（特性「時間重視」【企画 §5.2 の例】） |
| 行動 | **探る**（質問、忍耐1）／**提案**（忍耐1）／**人払いを願う**（忍耐1、1回だけ、気づき「人前では本音を言えない」が必要）／**締める**（忍耐0、交渉を終える） |
| 終了 | 締める、または忍耐0。合意書に何もなければ**既定案**が適用される |

v1 の AP、手札、ドローはなくしました。1ラウンドに1つの行動だけにし、**「探る」と「提案」が同じ忍耐を奪い合う**ことで、「情報を取るか、動くか」という判断の緊張を生みます。

### 3.4 提案の組み立て

提案は4種類の部品を組み合わせて作ります。部品は交渉卓に置くカードとして見せます。

| 部品の枠 | 最大数 | 企画書の役割との対応 |
|---|---|---|
| 求める（Ask） | 2 | — |
| 差し出す（Offer） | 2 | 条件交換 |
| 形（Form） | 1 | 選択肢の拡張 |
| 根拠（Evidence）：手掛かりを1枚添える | 1 | 根拠の提示 |

- 部品の初期セットは誰でも使えます（支度金、騎士小隊、準備期間、明朝出発、功績を王の名で、返済）。情報によって部品が増えます。
- 「共通利益の明示」と「信頼の回復」は、部品の効果（例：北の村の避難を手伝う → 王の「民」の利害を満たす）と心証の変化として表現します。
- 制約：
  - 合意書の同じ枠に入る条件は、同時に出せない（例：「準備期間」と「明朝出発」はどちらも「出発」の枠）。
  - すでに埋まった枠の条件は出せない。
  - 「形」は前提条件を持つ（例：段階支援には、報告の条件が同じ提案の中か、合意書にすでに入っている必要がある）。

### 3.5 相手モデル（王の利害）

王は**利害**と、その**重み**を持ちます。プレイヤーには最初は見えず、気づきと確信によって見えていきます。

| 利害 | 重み | 内容 |
|---|---|---|
| 国庫 | 3 | 倉を減らしたくない（隠れた事情：実は空に近い） |
| 時間 | 2 | 十日後の諸侯会議までに北の情報が欲しい |
| 面子 | 2（大臣が同席している間は3、人払いの後は1） | 人前で「金がない」「命令を断られた」と見られたくない |
| 民 | 1 | 北の民を守るという先王の誓い |

**受け入れの計算**【提案】

```
S = Σ（利害の重み × 提案の各部品がその利害に与える影響）＋ 心証の補正
心証の補正：警戒 −1 ／ 中立 0 ／ 好意 +1 ／ 信頼 +2

S ≥ 1   → 受諾（企画書の「譲歩」）
S = 0   → 対案（企画書の「要求強化」）：王が自分の好む条件を1つ足して返す
S = −1  → 保留（企画書の「防御」）：「考えておこう」。理由の手掛かりだけが返る
S ≤ −2  → 拒否（企画書の「拒絶」）：忍耐がさらに1減る。理由が面子なら心証も1下がる
```

- 影響の値は −2〜+2 の整数だけ。倍率は使いません（v1 の E5 の反省）。
- プレイヤーには **S の値を一切見せません**。見せるのは利害ごとの影響（反応予測）と心証だけです。
- 対案のときに王が足す条件の候補（好む順）：「功績を王の名で」→「明朝出発」。すでに入っているものや、枠が重なるものは飛ばします。足しても S が 1 以上にならなければ、対案ではなく保留にします。

### 3.6 反応と理由（反応から学ぶ）

- 受諾以外の反応には、**最もマイナスに効いた利害**の手掛かりが付きます。
- 理由の伝え方は、その利害の確度によって変わります：
  - **確信している場合**：言葉で返る（「倉がもたぬのだ」）
  - **未知・推測の場合**：仕草で返る（「王は大臣をちらりと見た」）。その利害は「推測」に上がる
- 例外：**人前で国庫の話をされると、王は理由を口にしない**（面子）。代わりに視線の手掛かりが出ます（→ §4 の C9）。
  - これにより、**情報なしで提案して断られた人も、断られたことで情報を得る**ことができます（再設計依頼「情報がなくても交渉できる」）。
- 受諾したときも、最もプラスに効いた利害を一言で返します（「会議に間に合うな」）。これで、成功の理由も学べます。

### 3.7 反応予測（相手の行動予測の再設計）

- 提案を組み立てている間、王の4つの利害ごとに予測を表示します：

| 確度 | 表示例 |
|---|---|
| 確信 | 国庫：▼▼（重要度：大） |
| 推測 | 面子：▼？ |
| 未知 | ？？（灰色） |

- 心証と、場の状況（「大臣の目」アイコン：面子の重要度が上がっていることを示す）も表示します。
- これにより、**情報を集めるほど、提案する前に結果が読める**ようになります。企画書の「相手の次の動きに備えたい」【企画 §3】を、利害の理解の深さで表現しています。

### 3.8 王の一手（相手の行動）

| ID | 条件 | 王の行動 | 予兆 |
|---|---|---|---|
| K1 期限の念押し | ラウンド開始時に忍耐が2、かつ合意書の「出発」が空 | 「明朝発て」と対案を出す。受ければ「明朝出発」が入る。断れば心証−1 | 忍耐3のとき「王は窓の日差しに目をやった」。時間の利害が確信なら「王は期日を切ってきそうだ」と補足 |
| K2 大臣の咳払い | 人前で初めてお金（支度金）を求めたとき | 大臣が咳払いをし、王が大臣を見る → 手掛かりC9 | なし（初回の驚き） |
| K3 人払い | プレイヤーが人払いを願い、受け入れられたとき | 大臣が退出する。以後、面子の重みは1。王が本音（C10）を語る。心証+1 | — |

### 3.9 合意書と結果判定

**合意書の枠**

| 枠 | 入る条件 | 空のままだと |
|---|---|---|
| 旅の支え | 支度金（大／小）、倉の余剰物資、商人への紹介状 のうち1つ（＋形） | なし |
| 同行者 | 志願騎士、騎士小隊 のうち1つ | なし |
| 出発 | 五日の準備期間 か 明朝出発 | 「三日以内」（王の当初の要求。主人公にも王にも±0） |
| 見返り | 報告、功績、避難支援、返済 から最大3つ | なし |

**既定案（BATNA）**：交渉の冒頭で大臣が示す。「何も決まらなければ、銀貨二十枚（支度金・小）と明朝の出発でよろしいかと」。合意書が空で交渉が終わると、これが適用されます。企画書§7の「代替案の把握」を体験の中に組み込んだものです。

**2軸の評価**【提案】
- **主人公の得（P）**：合意書の条件ごとの主人公側の値の合計（内訳は 支え／安全／準備／自由）
- **王の満足（K）**：合意書の条件ごとの王側の値（基本の重みで計算。人前・人払いの補正は使わない）の合計

| 結果 | 条件（上から順に判定） |
|---|---|
| 既定案 | 合意書が空のまま終了 |
| 双方納得 | P ≥ 2 かつ K ≥ 2 |
| あなた寄り | P ≥ 2 かつ K < 2 |
| 王寄り | P < 2 かつ K ≥ 2 |
| 妥協 | それ以外 |

- 補足表示：P が既定案の P（−1）を下回った場合、「既定案より不利な合意」と表示します（振り返りで、代替案を知っていたかどうかに触れるため）。
- 受け入れの計算では面子の重みに人前（3）・人払い後（1）の補正を使いますが、K の評価では基本の重み（2）を使います。人払いの後で通った合意は「その場では通ったが、王の本当の満足は低い」となり得ます。これは設計上の意図です（§4 のルートR6）。

### 3.10 振り返り

【企画】短く、説教調にしない。選択・相手の反応・ほかの方向性を示し、概念名は必要な範囲で添える。

1. **合意書と結末**：物語の言葉で表示する（例：「若い騎士と五日の猶予を得た。財布は軽い」）
2. **2軸の位置**：主人公の得と王の満足を、象限の図で示す
3. **王の本音**：4つの利害と重みを、このとき初めて全部明かす（「王が最も気にしていたのは国庫だった」）
4. **あなたの判断 3つ**：判断ログから影響の大きかったもの（例：「金額を求める前に、急ぐ理由を尋ねた」）
5. **あり得た別の合意**：**このプレイで持っていた手掛かりだけで**成立した、別の結果の合意を1つ示す。なければ「あと1つ手掛かりがあれば届いた」合意を、その入手先と一緒に示す
6. **概念タグ**：1〜2個（例：利害と立場の違い、選択肢の拡張、代替案の把握、面子）

5は、部品の組み合わせを実行時に全探索して求めます（組み合わせは数千通り程度なので軽い）。「唯一の正解ではない」ことを示すための仕組みです。

## 4. 王との謁見シナリオ（再設計）

固有名詞・設定はすべて検証用の仮のものです（企画書§14では未決）。

### 4.1 状況

王は主人公に、北の砦へ行って魔王軍の動きを探るよう命じる。主人公には支度・仲間・準備の時間が要る。

### 4.2 王の表の要求と本当の利害

| | 表の要求・立場（口にすること） | 本当の利害（口にしないこと） |
|---|---|---|
| 出発 | 「三日のうちに発て」 | 欲しいのは**会議前の情報**であって、早い出発そのものではない（時間） |
| 資金 | 「支度は大臣によきにはからわせる」 | **国庫は空に近い**。人前ではそれを言えない（国庫・面子） |
| 同行者 | 「騎士団は王都の守りで手一杯だ」 | 騎士団長に命じて断られる姿を人前で見せたくない。**志願者なら**問題ない（面子） |
| 民 | （語らない） | 先王の誓いどおり、北の民を守りたい。ここは主人公と**共通の利益**（民） |

### 4.3 手掛かり

| ID | 入手先 | 内容 | 役割 |
|---|---|---|---|
| C1 | 自宅：母 | 「北の村の叔母さんから、便りが途絶えているの」 | 部品「北の村の避難を手伝う」が開く／C8 と組み合わさって気づき H4 |
| C2 | 自宅：幼なじみ（商人見習い） | 「王家の紹介状があれば、組合はツケで品を出すよ。先代の王様のときもそうだった」 | 部品「商人への紹介状」が開く／**根拠**として示すと、紹介状を頼むときに王の面子が傷つかない |

## 6. クイズ化を防ぐための仕組み

| 心配 | 対策 |
|---|---|
| 正しい質問を当てるゲームになる | どの質問も何かが分かる（外れがない）。差は「何が分かるか」と「その時間を使うか」だけ |

## 7. バランスの不変条件（テストで保証すること）

1. 手掛かりを1枚も持っていない状態でも、受諾される提案が存在する（例：支度金（小）＋明朝出発＋功績を王の名で）。
2. 探索で得る手掛かり（C1〜C6）が0枚でも、謁見中の行動だけで双方納得に届く（R5）。ただし忍耐の余裕は1以下になる。
3. 手掛かり（謁見中に得るものも含む）を1枚しか持っていない状態では、双方納得に届かない。
4. 双方納得になる合意書の中身は、**4種類以上**あり、旅の支えの枠の中身（なし／物資／紹介状）が少なくとも3通りに分かれる。
5. 表の要求どおりの提案（支度金（大）だけ、または支度金（大）＋明朝出発）は、どの心証・場面でも受諾されない。支度金（大）は、段階支援・返済・報告などで国庫と時間の利害に手当てをすれば通り得る（これは「解き方の1つ」として許容する）。
6. P と K の両方で最大になる**支配的な合意書**が存在しない。
7. 受け入れの計算 S は、すべての部品の組み合わせで −12〜+12 に収まる（読みやすさの確認）。

**設計時点の検算結果**（簡易スクリプトで手計算を確認したもの。本番の全探索テストに置き換える）
- R0〜R6 の S と P/K は、本文の値と一致した。
- 手掛かり1枚だけで双方納得に届く合意書はなかった（不変条件3を満たす）。
- 支度金（大）だけ、または支度金（大）＋明朝出発は、人前・人払い後、心証が最大でも受諾されなかった（不変条件5を満たす）。
- 全手掛かりを持ち、根拠を最良に使った場合、双方納得になる合意書は109通りあり、支配的なものはなかった（P の最大5、K の最大9は別々の合意書）。
- **課題**：109通りのうち66通りに「倉の余剰物資（A3）」が含まれる。A3 は P+2 で王に負担がないため、手に入れば迷わず使う部品になっている。対策案：「古い装備」として安全−1を付ける、王の別の利害（例：「非常時の備え」）に −1 を付ける、など。【未決】U-S7

## 9. 将来の拡張（MVPの範囲外）【提案】

- **技法カード（デッキ構築の再導入案）**：振り返りで身に付けた概念（例：「理由を尋ねる」「既定案を確かめる」「人払い」）が、次のシナリオから使える**技法**としてデッキに加わる。技法は探りや提案を強化する（例：「沈黙」— 保留のときに追加の理由を引き出す）。企画書§5.2のデッキ構築と、30〜40枚という規模に、シナリオをまたいだ成長としてつなげる。
- **ランダム要素**：プレイごとに王の利害の重みを入れ替える（国庫より面子を重く見る王など）。同じ部品でも、別の解き方が必要になる【企画 §5.2「毎回同じ手順では解けない」】。
- **ハードモードの自由入力**：自由入力をキーワードやルールベースで探り・部品へ対応付ける。モデルが同じなので、将来AIを入れても、出力を「探り／部品」に変換すれば交渉側は変わらない【企画 §5.1】。
- **ボス交渉**：複数の相手（王と大臣など）が異なる利害を持つ、多者間の合意書。
