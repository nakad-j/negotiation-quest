# 紙プロトタイプ v1「三日の勅命」

- 目的：**交渉そのものが面白いか**を、プログラムなしで確かめる
- 検証する体験：情報を見つける → 読みを立てる → **王に直接ぶつける** → 王の反応に対応する → 提案を練る → 合意する
- 所要時間：準備10分／プレイ25〜35分／振り返りの聞き取り10分
- 人数：プレイヤー1人＋進行役（王・大臣・城の人々を演じる）1人。観察役がもう1人いると理想的

> このフォルダは実験用の資料です。`docs/` の設計書とは独立しています。ここで分かったことを設計に反映するかどうかは、プレイ後に判断します。

> **このREADMEは進行役・観察役向けです。プレイヤーに渡すのは `player_handout.md` だけにしてください**（ほかのファイルには、展開の手がかりが含まれています）。

## ファイル

| ファイル | 誰が読むか | 内容 |
|---|---|---|
| `player_handout.md` | プレイヤー（印刷して渡す） | 導入、自分の事情、城で調べられる場所、合意メモ |
| `facilitator_guide.md` | **進行役だけ**（プレイヤーに見せない） | 進行のすべて（準備と、迷ったときの確認用） |
| `quick_reference.md` | **進行役だけ**（プレイ中に手元に置く） | 我慢の表、判断チェック、日数、王の一手の早見表 |
| `observation_sheet.md` | 観察役または進行役 | プレイ中の記録欄と、プレイ後の聞き取り |

## 用意するもの

- 印刷したプレイヤー資料
- **情報カード**5枚（②〜⑤は「基本」と「追記」に分ける）と**本音カード**4枚：`facilitator_guide.md` の §9 を切り取るか、付箋に書き写す
- **王の我慢**を表すコイン7枚（あるいは数字を書いた紙）
- メモ用紙（プレイヤーが合意メモを書く）
- タイマー（任意）

## 遊び方の要点

1. **プレイヤーは自分の言葉で自由に話します**。選択肢は読み上げません。進行役は、発言を「尋ねる／読みをぶつける／提案する／王の提案に応じる／締める」のどれかとして受け取り、ガイドの表に従って王として返します。
2. ガイドにない発言が出たら、§5「王の判断チェック」で王として判断してください。**台本にない良い提案こそ、このテストで一番知りたいことです**。観察シートに必ず書き残してください。
3. 進行役は、王を「意地悪な出題者」ではなく、**自分の都合で動く一人の人物**として演じてください。

## 2つのモード

- **モードA：自由発話**。交渉らしさが成立するかどうかを見ます。**初回のプレイテストはこのモードだけで行います。**
- **モードB：台詞カード（初回は非推奨）**。製品版に近い「用意された選択肢から選ぶ」形でも面白さが残るかを見るためのモードです。ただし今のカードは正しい読みと解決策をそのまま並べてしまうため、選択式の問題になりやすい状態です。モードAの結果を見てから作り直します。

## 一人で試したい場合

進行役ガイド（このREADMEも含む）を読むと秘密が分かってしまいます。自分でプレイヤーを体験したいときは、まだ何も読んでいない段階で、次のどちらかにしてください。
- 同僚や友人に進行役を頼む
- Claude（このチャット）に進行役を頼む。「`facilitator_guide.md` に従って王を演じて」と依頼すれば、ガイドのルールに沿って進行します（ガイドの範囲を超えて即興はしない、という条件付き）
