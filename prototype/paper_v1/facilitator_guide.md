# 三日の勅命 — 進行役ガイド（プレイヤーに見せないこと）

このガイドがあれば、王と城の人々を演じて交渉を進行できます。
**全部を覚える必要はありません。** 最低限、次の3つを押さえてください。§2 王の本心、§3 我慢のルール、§5 王の判断チェック。そのうえで、表にない発言が来たら §5 で判断します。
プレイ中は `quick_reference.md`（早見表）を手元に置き、このガイドは事前の準備と、迷ったときの確認に使ってください。

> **初回のプレイテストはモードA（自由発話）だけで行います。** §10 のモードBは、まだ使わないでください。

## 0. 進行の流れ（目安30分）

| 段階 | 時間 | 進行役のすること |
|---|---|---|
| 導入 | 3分 | プレイヤー資料 §1〜2 を読んでもらう。**情報カード①紹介状の前例**を渡す |
| 第一幕 | 2分 | §4 の王の台詞を読む。読み終えたら、合意メモの右の列に王の条件を書いてもらう（出発：三日以内／物資：銀貨二十枚／仲間：なし／王への約束：密書を届ける） |
| 城の探索 | 5〜8分 | 3か所を選んでもらい、§6 の人物を演じる。会話の後に情報カード（基本）を渡す。掘り下げた場合は追記も渡す |
| 第二幕 | 12〜18分 | 我慢コインを7枚置く。§7 で交渉する。**5回目の発言の前**に §8 の転機を入れる |
| 合意・後日談 | 3分 | §11 で後日談を読み上げる |
| 王の日記 | 1分 | §12 を読み上げる |
| 聞き取り | 10分 | 観察シート |

## 1. 舞台と人物

- **アルダン王**：50代。北の砦に人を送りたい
- **大臣ヘルマン**：王の財布番。謁見に同席する。国庫の秘密を守ることが第一
- **書記官ミラ**、**鳩番の老人グラム**、**倉番トーゴ**、**衛兵カイ**：城の人々
- **騎士セレン**：北行きを志願した若い騎士。登場はしない
- **守将ボルク**：北の砦を守る将。密書の宛先

**日の数え方**：謁見の日（今日）を**0日目**とします。「三日以内に出発」は遅くとも3日目に出発、「五日後に出発」は5日目に出発、という意味です。

**距離と日数**（プレイヤーに聞かれたら、王か城の者として、そのまま答えてよい）
- 北の砦まで：徒歩で**3日**、荷車なら**5日**
- 伝書鳩：砦から王都まで**2日**
- 早馬の使者：砦から王都まで**3日**
- 北街道の町ハルデン：王都から早馬で**1日**。ハルデンから砦までは荷車で**2日**
- 諸侯会議：**10日目**（これはプレイヤーには自分からは言わない。§6 書記官から得られる）

## 2. 王の本心

### 2.1 隠れた事情（王は自分からは言わない）

| # | 事情 | 王が隠す理由 |
|---|---|---|
| 真1 | **10日後の諸侯会議までに、北の確かな報せが要る**。会議で諸侯は北を見捨てるかどうかを決める。王は見捨てたくないが、報せがなければ諸侯を説得できない | 弱みを見せれば、旅人に足元を見られる |
| 真2 | **金庫はほぼ空**。城壁の修繕で使い果たした。出せるのは大臣が用意した銀貨二十枚まで | 王が金に困っていると知れれば、王の権威が揺らぐ。**人前では絶対に認めない** |
| 真3 | **騎士団長は北への派兵に反対**している。王が命じて断られれば、王の言葉は軽くなる。だから「騎士は出せぬ」と言う。ただし志願者がいるなら、王は「許す」だけでよい | 人前で認めれば恥になる |
| 真4 | **密書の中身**は守将ボルクへの指図。「砦が守れぬなら、民を連れて南へ退け。責めは王が負う」 | 会議の前にこれが漏れれば、「王は北を捨てた」と諸侯に言われる。**中身は最後まで明かさない**（転機の後に二人きりなら、半分だけ明かす。§7.8 参照） |

### 2.2 王の狙い（王が自分から取りに来るもの）

1. **密書を確実に届けさせる**（最優先。断られると強く押す）
2. **会議の前に報せを得る**
3. **金貨を出さずに済ませる**
4. **できれば、旅人の功績を「王家の手柄」にする**（会議で「王の手の者が北を見てきた」と言えるように）

### 2.3 王が知りたいこと（王もプレイヤーを読む）

- なぜこの役目を受けるのか（動機）
- 途中で逃げないか
- どこまで知っているか

**「王が知ったことメモ」** を手元に作り、プレイヤーが漏らしたことを書き留めてください（叔母のこと、金に困っていること、名誉が欲しいこと、など）。王はそれを交渉で使います（§7.6）。

### 2.4 人物像と演技の指針

- 疲れているが、頭は切れる。**短く話す。質問には質問で返す**ことが多い
- **嘘はつかない。ただし、言わない、はぐらかす、相手の思い込みを利用する**。これはフェアさを保つための大事なルールです
- 見抜かれると一瞬黙り、面白がる（「……ほう」）。見抜いた相手には敬意を払うようになる
- **人前で**弱み（金庫、団長）を突かれると、冷たく怒る
- 民の話になると、声が少し低くなる（プレイヤーへの小さなヒント）
- 早く、安く決めたい。だらだら話すと苛立つ
- 大臣ヘルマンは、口数は少ないが、金の話になると咳払いをする。王はそのたびに大臣を見る

## 3. 王の我慢（コイン7枚）

コインはプレイヤーに見える場所に置きます（隠すと面白いかどうかは、観察で確かめたい点の一つです）。

| プレイヤーの発言 | 我慢 |
|---|---|
| 尋ねる（王が答えても、はぐらかしても） | −1 |
| **正しい読みをぶつける** | **±0**。王は認め、本音カードを渡す（人前の場合の例外は §7.3） |
| 外れた読み | −1。**2回続けて外れたら、2回目からは−2**（王「当て推量はやめよ」） |
| 半分だけ当たった読み（§7.3） | −1。王は核心の手前まで明かす（本音カードは渡さない） |
| **人前で**金庫や団長の弱みをはっきり口にする | −2（王は認めない） |
| 提案が受け入れられる | ±0 |
| 提案に対案が返る、または提案が断られる | −1 |
| 王の求めに応じる | **+1**（上限7） |
| 王の求めを断る | −1 |
| 辞退をちらつかせる（「お受けできません」） | −1。ただし1回だけ、王が1つ譲る（§7.7） |

- **0になったら打ち切り**：王「もうよい。明朝発て」
  - それまでに合意した項目は残る
  - 空欄の項目は既定の条件になる。ただし、**出発が空欄なら「明朝」**になる
  - 転機（§8）の前に打ち切りになった場合は、§11.3 も適用する
- **初めて3以下になったとき（1回だけ）**：出発がまだ決まっていなければ、王の一手「期限の念押し」（§7.6）が起きる
- 転機の後は、外れた読みと、断られた提案は**常に−2**になる（§8）

## 4. 第一幕（読み上げ）

> **王**：「そなたが北へ行くという者か。……よい。用件は三つだ」
> **王**：「一つ。**三日のうちに発て**。それ以上は待てぬ」
> **王**：「二つ。支度は大臣に任せる。ヘルマン」
> **大臣**：「は。**銀貨二十枚**をご用意いたします」
> **王**：「三つ。**騎士は出せぬ**。騎士団は王都の守りで手一杯だ」
> **王**：（封蝋の付いた書状を掲げて）「それと、**これを砦の守将ボルクに届けよ。中身は問うな**」
> **王**：「正午にもう一度来い。それまでに腹を決めておけ」

プレイヤーが第一幕で何か言おうとしたら、王は「正午に聞く」とだけ返します。

## 5. 王の判断チェック（すべての提案はこれで判断する）

提案が来たら、王になりきって次の問いに答えてください。**表にない提案も、これで判断できます**。

**大原則：その提案が触れている点だけを見る。** ✕になるのは、その提案によって王の事情が**今より悪くなる**場合だけです。触れていない点は「−」（判定に使わない）とします。例：紹介状の提案は報告に触れていないので、問1は「−」です。

| # | 王の問い | ○ / ✕ |
|---|---|---|
| 問1 | **会議（10日目）までに、北の確かな報せが届くか？**（出発の時期や報告の方法に触れる提案だけ） | 間に合う → ○（大）／間に合わなくなる → ✕ |
| 問2 | **王の懐が痛むか？** | 金貨を求める → ✕（銀貨二十枚までは大臣が用意済みなので可）<br>金の代わりに、王の懐を痛めない手段を出す（紹介状など）→ ○<br>**倉の物資**：人前では大臣が反対する → ✕（保留扱い）。二人きり、R2' の後、または転機の後なら → ○ |
| 問3 | **人前で王の権威が傷つくか？**（金庫が空だと匂わせる、王が団長に命じる形になる） | 傷つく → ✕ |
| 問4 | **密書は届くか？**（密書に触れる提案だけ） | 届けない、または中身を見せろと言われる → ✕ |
| 問5 | **（転機の後だけ）8日目までに砦へ糧が届くか？**（§8） | 届く → ○（大）／届かなくなる → ✕（「民が飢える」） |

**判定**
- **✕が1つでもある** → 断るか、✕を消す**対案**を出す。断るときは、理由の**片鱗**を必ず見せる（表情、言い淀み、大臣を見る）
- **✕がなく、○がある** → 受け入れる。**最初に受け入れるとき**だけ、王の一手「功績は王家の名で」（§7.6）を付け足す。プレイヤーがすでに功績を申し出ていれば省く
- **✕も○もない** → 保留。「それで余に何の得がある」

**王に何かを出させる提案**（馬、人、武器、地図など、上の表にない物や人）
- ✕がなければ、王は**見返りを求める対案**を返します。「よかろう。代わりに〜」の形にし、〜には王の狙い（§2.2）から1つ選びます（密書を必ず届ける、功績を王家の名で、出発を早める、など）
- 王都の守りに関わる人（騎士、衛兵の隊）を求められたら、問3と同じ扱いにします。人前で王が団長に命じる形になるなら✕です

**日数の計算例**（問1の判定に使う。今日が0日目）

| 出発 | 報告の方法 | 王に届く日 | 問1 |
|---|---|---|---|
| 三日以内 | 早馬を返す | 3＋3＋3＝9日目 | ○ |
| 三日以内 | 鳩 | 3＋3＋2＝8日目 | ○ |
| 五日後 | 早馬を返す | 5＋3＋3＝11日目 | ✕（「会議に間に合わぬ」） |
| **五日後** | **鳩** | 5＋3＋2＝**10日目の朝** | **○（「……ぎりぎりだな」）** |
| 明朝（1日目） | 鳩 | 1＋3＋2＝6日目 | ○ |

鳩で報告する計画は、すべて**鳩を籠で持って行く**ことが前提です（下の注意を参照）。

- **鳩の注意**：砦の鳩は尽きている（§6 鳩小屋）。鳩で報告するには、**プレイヤーが鳩を籠で持って行く**必要がある。プレイヤーが「鳩で報告します」とだけ言った場合、王は「砦の鳩が戻らぬのだぞ」と返す。鳩小屋で話を聞いていないプレイヤーでも、ここで「では鳩を連れて行けばいいのでは」と思いつけば、それで成立する。
- 王は鳩を持って行かせることを思いついていません（砦の鳩が尽きたと思い込んでいる）。プレイヤーがそれを言ったとき、王は感心します。

## 6. 城の探索（3か所まで）

**演じ方**：最初に下の「最初の一言」を言い、プレイヤーの質問に答えます。質問がうまくなくても、**会話が終わったら情報カードの「基本」を渡してください**（情報が手に入らない場所は作らない）。

**掘り下げの判定**：プレイヤーが「聞かれたら」の内容を聞いた後で、**もう一歩踏み込んだ質問**をしたら（話題は問わない）、「さらに聞くと」の内容を話し、カードの**「追記」**も渡します。踏み込まなければ追記はありません。

### 書記の間（書記官ミラ） → 情報カード②
- 最初の一言：「ごめんなさい、手が離せないの。招集状をあと三通……」
- 聞かれたら：「**諸侯会議の招集状**よ。十通。**十日後**に諸侯が集まるの」
- さらに聞くと：「議題？ ……**『北の守り』**とだけ書けって。砦は落ちてないわよ。便りが途絶えただけ」

### 鳩小屋（鳩番グラム） → 情報カード③
- 最初の一言：「鳩に用か。ここの鳩は北の砦まで**二日**で飛ぶぞ」
- 聞かれたら：「砦から鳩が戻らんのは、**砦の鳩が尽きた**からじゃろう。あそこには十羽もおらんかった」
- さらに聞くと：「**持っていくなら、籠で六羽貸せる**。陛下のお許しがあればな」

### 倉（倉番トーゴ） → 情報カード④
- 最初の一言：「何だ、旅人か。倉番は俺一人になっちまったよ」
- 聞かれたら：「**金庫番も三人から一人に減らされた**。城壁の修繕で、えらい金が出ていったらしい」
- さらに聞くと：「倉には**去年の保存食と、古い鎖帷子が手つかず**だ。大臣様は『非常の備え』だと言って出さん」

### 練兵場（衛兵カイ） → 情報カード⑤
- 最初の一言：「北へ行くって？ 物好きだな」
- 聞かれたら：「若い騎士の**セレン**が北行きを志願したんだ。でも団長が『**王命がなければ出さん**』って突っぱねた」
- さらに聞くと：「陛下と団長は、この件で大喧嘩したらしい。……北行きに名乗りを上げたのは、**あんたとセレンだけ**だよ」

## 7. 第二幕：交渉

### 7.1 開幕（読み上げ）

> **王**：「腹は決まったか。……その前に一つ聞く。**そなた、なぜこの役目を受ける？**」

**プレイヤーの答えを「王が知ったことメモ」に書きます。** 答えによって、王の態度が変わります。

| 答え | 王の反応 | その後 |
|---|---|---|
| 家族・叔母・故郷のため | 「……そうか。北に縁者がおるのか」 | メモに「叔母」。転機の後に使う（§7.6） |
| 報酬・金 | 「金で動く者は、金で寝返る」 | 王は金ではなく**名誉**で釣ろうとする（「功績を王家の名で歌わせよう。それが報酬だ」） |
| 名誉・腕試し | 「若いな。嫌いではない」 | 王はおだてて急がせる |
| 王命だから | 「殊勝なことだ」 | 王は遠慮なく押してくる（要求を強める） |
| 答えない・はぐらかす | 「……用心深いな。よかろう」 | 王もはぐらかしが増える |

この最初のやりとりは、我慢を減らしません。

### 7.2 質問への反応（我慢−1）

| 質問 | 王の答え（人前） | 片鱗・備考 |
|---|---|---|
| なぜ三日なのか | 「北の様子が分からぬのは困る。それだけだ」 | 「それだけ」で目をそらす |
| 支度金を増やせないか／いくら出るのか | 「支度は大臣に任せたと言った」 | **大臣が咳払い。王は大臣を見る** |
| なぜ騎士を出せないのか | 「王都の守りで手一杯だと申した」 | 2回目は「くどい。……志願した若造がおるとは聞いたが、団長が許さぬそうだ」（苛立つ。セレンの存在が分かる。情報⑤がない人への経路） |
| 密書の中身は | 「問うなと言った」 | — |
| 砦の様子は | 「分からぬから行かせるのだ」 | — |
| 会議について（情報②を持っている） | 「……書記官め。口の軽い」 | そのまま読みにつなげたら §7.3 の R1 として扱う |
| 鳩について | 「砦の鳩は戻らぬ。尽きたのだろう」 | 情報③がなくても、これがヒントになる |

### 7.3 読みをぶつけたときの反応

**正しい読み**（我慢±0。本音カードを渡す）

| # | 読み（言い回しは自由） | 人前での反応 | 二人きりでの反応 |
|---|---|---|---|
| R1 | 急ぐのは、**会議までに北の様子を知りたい**からでは | 「……ほう」（沈黙）「そうだ。十日後、諸侯は北を捨てるかどうか決める。余は知らねばならん」→ **本音カード1** | 同じ |
| R2 | **金庫が苦しい**のでは | **認めない**。冷たく「余の金庫を案じるとは、大した旅人だ」。大臣がにらむ。**我慢−2** | 「……修繕で使い果たした。銀貨二十枚が精一杯だ」→ **本音カード2** |
| R2' | 金貨でなくてかまいません。**眠っている物でも**（遠回しに言う） | 王の口元がゆるむ。「……ヘルマン、何か眠っておるか」→ 大臣「倉に古い物が」（渋々）。我慢±0。本音カードは渡さないが、**倉の物資が交渉の材料になる** | — |
| R3 | 団長に命じて**断られるのを避けて**おられるのでは | 「口を慎め」。**我慢−2**。ただし王は一瞬、言葉に詰まる（片鱗） | 「……命じて断られれば、王の言葉は紙切れだ」→ **本音カード3** |
| R3' | 志願者がいるなら、陛下は**お許しになるだけ**で済むのでは | 提案として扱う（§7.4 P7） | 同じ |
| R4 | 密書は、**砦を捨てる指図**では | 長い沈黙。「……それを二度と口にするな」。王は警戒し、**「この話は誰にも言わぬと誓え」と求める**（応じれば+1、断れば−1） | 転機の後なら §7.8 |

**半分だけ当たった読み**（我慢−1。王は否定せず、核心の手前まで明かす。本音カードは渡さない）

自由発話では、これが一番多く出るはずです。王は**認めも否定もせず、一歩だけ明かします**。プレイヤーがそこから核心を突けば、正しい読みとして扱います。

| 読みの例 | 王の反応 |
|---|---|
| 「何か期限があるのでは」「急ぐ理由があるのでは」 | 「……十日後に、ある集まりがある。それ以上は言わぬ」 |
| 「お金のことで何かご事情が」（人前で、遠回しに） | 王は黙って大臣を見る。大臣が咳払いをする |
| 「騎士団と何かあったのですか」 | 「騎士団には騎士団の事情がある」（言葉に詰まる） |
| 「密書には、何か大事なことが」 | 「大事でなければ、そなたに託さぬ」 |
| 「北の民のことを気にかけておられるのでは」（転機の前） | 下の W4 と同じ扱い |

**外れた読み**（我慢−1。2回続けて外れたら、2回目からは−2）

| # | 読み | 王の反応（嘘はつかず、思い込みを利用する） |
|---|---|---|
| W1 | 魔王軍がすぐにも攻めてくるのですね | 「そう思うなら、なおさら急げ。**明朝発て**」（王は否定しない。プレイヤーの焦りを利用して押してくる） |
| W2 | 私を信用しておられないのでは | 「信用せぬ者に密書は託さぬ」。大臣が鼻で笑う |
| W3 | 私を試しておられるのですね | 「試されていると思うなら、励め」（面白がるだけで、情報はない） |
| W4 | 民を案じておられるのでは（転機の前） | 「王が民を案じるのは当然だ」（はぐらかす。ただし声が少し低くなる） |

W4は転機の後なら正しい読みとして扱います（±0。王は「……民を見捨てた王にはなりたくない」と漏らす）。

### 7.5 人払い（1回だけ）

プレイヤーが、理由を添えて二人きりで話したいと願ったとき（例：「大臣殿の前では申し上げにくいことが」）。
- **我慢が3以上なら受け入れる**：「……ヘルマン、下がれ」。大臣は不満そうに退出する。メモに「大臣の恨み」と書く
- **我慢が2以下なら**：「そんな暇はない」
- 二人きりのあいだ、王の口調は少し柔らかくなる。R2、R3 を認め、P6 を受け入れる
- **転機が起きると、大臣が鳩の知らせを持って戻ってくる**（二人きりの時間はそこで終わる）

### 7.6 王の一手（王が自分から仕掛ける）

| 一手 | いつ | 王の台詞 | プレイヤーの選択 |
|---|---|---|---|
| **功績を王家の名で** | 最初に提案を受け入れたとき（すでにプレイヤーが申し出ていれば省く） | 「代わりに、そなたの功績は王家の名で語れ。吟遊詩人にもそう歌わせる」 | 応じる（+1）／断る（−1）／条件を付ける（§5 で判断） |
| **期限の念押し** | 我慢が初めて3以下になったとき（1回だけ）。出発がまだ決まっていない場合だけ | 「余の我慢にも限りがある。**明朝発つと言え。そうすれば城の地図の写しを持たせよう**」<br>転機の後なら「**荷車と明朝発て。地図の写しも持たせる**」 | 応じれば、出発は明朝、その他に「地図の写し」が入る、我慢+1 |
| **名誉で釣る** | 開幕で「報酬」と答えた人に、適当な場面で | 「金より名だ。北を見てきた者として、会議で名を呼んでやろう」 | — |
| **縁者を使う** | 転機の後。メモに「叔母」がある場合 | 「砦に逃げ込んだ民の中に、そなたの叔母もおるやもしれぬな。**今夜にも発ちたかろう**」 | 王はこれで「明朝・荷車付き」を強く押す |
| **口止め** | R4 を人前で言われたとき | 「この話は誰にも言わぬと誓え」 | 誓う（+1）／断る（−1、王は以後警戒する） |

### 7.7 辞退をちらつかせたとき、王のはったり

- プレイヤーが「その条件ではお受けできません」と言ったとき（1回目）：王は**1つだけ譲る**。プレイヤーが一番こだわっている項目で、§5 で✕にならない範囲で譲る。我慢は−1。メモに「脅した」と書く（日記に影響する）
- 2回目：「ならば去れ」。そのまま交渉を続けるなら、プレイヤーが引くまで王は何も言わない
- 王が「他の者を探すまでだ」とはったりを言ったとき：
  - プレイヤーが**情報⑤（名乗り出たのは二人だけ）**を持ち出したら、王は長く黙ってから笑う。「……城の者は口が軽い。よかろう、そなたしかおらん」。**その後、王は二度とはったりを使わない。** この返しは我慢を減らさない

### 7.8 密書の中身（転機の後、二人きりのときだけ）

転機の後、プレイヤーが改めて人払いを願い、密書について真剣に問うたとき（人払いをすでに使っていても、このときだけは例外として受け入れる）：
> **王**：「……守将への指図だ。**守れぬなら、民を連れて退けと書いた。責めは余が負う**。会議の前に漏れれば、余は北を捨てた王になる。だから問うなと言った」
→ **本音カード4**

## 8. 転機（第二幕の5回目の発言の前に、必ず入れる）

5回目の発言の前に、交渉を止めて読み上げます。開幕の「なぜこの役目を受ける？」への答えは回数に数えません。
（プレイヤーが4回目までに締めた場合は、転機は後日談で起きます。§11.3）

> 扉が開き、**大臣ヘルマン**が駆け込んでくる。手には小さな筒。
> **大臣**：「陛下！ **北の砦から鳩が**！」
> **大臣**（読み上げる）：「『砦はなお持ちこたえる。されど**エダ村ほか二村の民、百二十名が砦に逃げ込みたり**。**糧は十日ともたず**。**これが最後の鳩なり**』」
> **大臣**：「……この鳩が放たれたのは二日前。**糧が残るのは、今日からあと八日**にございます」
> （王は長く黙る）
> **王**：「……ヘルマン。**倉を開けよ**」
> **大臣**：「陛下、あれは非常の備えにございます！」
> **王**：「**今が非常でなくて何だ**」
> **王**（プレイヤーに向き直って）：「話が変わった。**荷車に糧を積んで、明朝発て**」

**転機の後に変わること**
- 判断チェックに **問5「8日目までに砦へ糧が届くか」** が加わる。荷車は5日かかるので、**荷車は遅くとも3日目に出発**しなければならない
- 王の最優先が「報せ」から「**民と糧**」に変わる。倉の物資は、もう王にとって負担ではなく、**王自身が送りたいもの**になる
- 「最後の鳩」なので、砦から報告を飛ばすには、**鳩を持って行くことがいっそう重要**になる
- 王は大臣と対立した。プレイヤーがどちらに付くかで、大臣の態度が変わる（王の側に付けばメモに「大臣の恨み」）
- 王の焦りが増すので、以後、**外れた読みと断られた提案は常に我慢−2**
- メモに「叔母」があれば、§7.6「縁者を使う」が起きる
- 叔母が砦にいるかどうかは**誰にも分からない**（後日談で分かる）

**転機の後に想定される解決の例**（表にない案も、§5 で判断する）

| # | 提案 | 判定 |
|---|---|---|
| T1 | 王の言う通り、荷車を率いて明朝発つ（見返りに倉の装備、セレン、地図などを求める） | ○。糧は1＋5＝6日目に届く。鳩なら報せは8日目。ただしプレイヤーは準備の時間を失う |
| T2 | **荷車は明朝、セレンと衛兵に先に出させる**（王が志願を許すだけ）。**自分は四〜五日準備して徒歩で追い**、鳩を持って行って報告する | 糧は6日目（問5○）。自分が5日目に出れば、5＋3＋2＝10日目に報せ（問1○、鳩があれば）。問3○。**王は感心する**：「……荷と人を分けるか。考えたな」 |
| T3 | 三日目に荷車と出発。鳩で報告 | 糧は3＋5＝8日目でぎりぎり間に合う（問5○）。報せは10日目（問1○）。王は「八日目か。……民がもつなら、よい」 |
| T4 | 紹介状で、北街道の町ハルデンの組合から糧を買い、砦に運ばせる | ハルデンへ早馬で1日、そこから荷車で2日なので、糧は3日目に届く（問5○）。代償は組合への大きな借り（あなたの名前で） |
| T5 | 五日の猶予にこだわる（荷車も五日目） | 糧は5＋5＝10日目で**間に合わない**（問5✕）。報せも12日目（問1✕）。王は「民を飢えさせる気か」と強く押す。応じなければ我慢−2 |

## 11. 合意と後日談

### 11.1 読み上げ方

合意メモの各項目について、下の断片を順番に読み、最後に §11.2 の「叔母の運命」と §12 の日記を読みます。全体で1〜2分です。

| 出発：三日以内 | 三日で靴と外套は整った。地図の写しは間に合わなかった |
| 出発：五日後 | 五日のあいだに、地図を写し、靴を慣らし、北の言葉をいくつか覚えた |

| 糧が間に合わなかった（T5、または荷車なし） | 砦に着いたとき、糧はすでに尽きていた。何人かは、春を待たずに死んだ |

### 11.2 叔母の運命

- **叔母は砦に逃げ込んだ民の中にいる**
- 糧が8日目までに届いた場合：「砦の粥の列に、叔母がいた。痩せていたが、あなたを見て笑った」
- 届かなかった場合：「叔母は生きていた。だが、隣の家の子どもは助からなかったと、小さな声で言った」
- 転機が起きる前に締めた場合は、§11.3 の結果に従う

### 11.3 転機の前に締めた場合（転機の前に打ち切りになった場合も同じ）

> 城を出たその夜、宿の戸を叩く者がいた。王の使いだった。「**砦から鳩が来た。民が逃げ込み、糧が足りぬ。糧を積んだ荷車を連れて、明朝発て。王命である**」

- **翌朝（1日目）に荷車と出発**する。出発の予定に関係なく、**準備は打ち切り**になる（五日の猶予は失われる）
- 糧は1＋5＝6日目に届くので、民は助かる。鳩を持っていれば報せは8日目、早馬なら9日目に届く
- 合意で得たものは残る。後日談は、「荷車：一緒に率いた」の断片を加えて読む

## 13. 進行役のコツ

- **王は出題者ではありません。** プレイヤーが正解を言うのを待つのではなく、王の狙い（§2.2）を自分から取りに行ってください。プレイヤーが黙ったら、王が押す番です
- **片鱗は必ず見せてください。** 断るときに理由のヒント（目線、言い淀み、大臣の咳払い）がないと、ただの拒否に感じられます
- **表にない良い発言には、気前よく応えてください。** その発言を観察シートに残すことが、このテストの最大の収穫です
- **迷ったら、王の都合で決めてください。** 「この王なら、これで得をするか？」
- 我慢コインは、テンポよく、物理的に取り去ってください。音や動きが緊張を生みます
- 謁見の流れを止めないでください。ルール確認が必要でも、王として「……考えさせろ」と言ってから表を見れば、演出になります
