## C. プレイ後の聞き取り（約10分）

**最初は誘導しない質問から。** 順番に聞き、答えはできるだけ原文で書き留めてください。

1. 「どうでしたか？」（最初の一言をそのまま書く）
2. 「一番印象に残った場面はどこですか？」
3. 「王はどんな人でしたか？」（性格を語れるか。「出題者」ではなく「人物」として語っているか）
4. 「王は何を考えていたと思いますか？」（日記の前の理解と、後の理解を比べる）
5. 「自分の言ったことで、状況が変わったと感じた瞬間はありましたか？」
6. 「迷った場面はありましたか？ 何と何で迷いましたか？」
7. 「『正解を当てる』感じでしたか？ それとも『相手とやりとりする』感じでしたか？」（どちらの言葉を使うかに注目する。10段階で：当てる 1 ← → 10 やりとり）
8. 「理不尽だと感じた場面はありましたか？」
9. 「もう一度遊ぶとしたら、何を変えてみたいですか？」（**具体的な行動が出てくるか**）
10. 「このゲームが店頭にあったら、どんなゲームだと友達に説明しますか？」
11. （モードBのみ）「台詞を選ぶ形は、自由に話すのと比べて窮屈でしたか？」
12. 「他に何か言いたいことはありますか？」

**最後に（行動で見る）**：「もう一回やってみます？」と軽く聞く。

| 反応 | 記入 |
|---|---|
| 即答で「やる」／少し考えて「やる」／「今はいい」 | |
| やるなら、最初に何を変えると言ったか | |

## E. 複数人を終えた後の集計

| 指標 | P1 | P2 | P3 | P4 | P5 | 判断の目安 |
|---|---|---|---|---|---|---|
| 「あっ」の瞬間の数 | | | | | | 1人1回以上 |
| 自分から読みをぶつけた | | | | | | 過半数 |
| 台本外の提案があった | | | | | | 1人でもいれば大きな収穫 |
| 王を人物として語った | | | | | | 過半数 |
| 「当てる ↔ やりとり」の点数（10段階） | | | | | | 平均7以上 |
| 転機で計画を作り直した | | | | | | 過半数 |
| 理不尽を感じた場面 | | | | | | 共通する場面があれば直す |
| 「もう一回」に即答 | | | | | | 半数以上 |
| 結末の分類 | | | | | | ばらつきがあるか |

**判断の目安**
- 「もう一回」が半数以上で、王を人物として語り、「やりとり」寄りの点数が多い → **この方向で設計を進める**
- 「当てる」寄りの点数が多い、または台本外の発言がほとんど出ない → **読みをぶつける形がまだクイズになっている**。王の能動性と反応の幅を見直す
- モードAは面白く、モードBで大きく落ちる → 製品版で**選択肢をどう見せるか**が最大の課題になる（設計を進める前にここを詰める）
