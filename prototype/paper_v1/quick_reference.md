# 進行役の早見表（プレイ中に手元に置く・プレイヤーに見せない）

詳しくは `facilitator_guide.md` の各節を参照。**ここに新しいルールはありません。**

## 王の芯（§2）
- 狙い：①密書を届けさせる　②会議（10日目）前に報せ　③金貨を出さない　④功績を王家の名に
- 隠すこと：会議の意味／金庫は空（**人前では絶対に認めない**）／団長に断られたくない／密書の中身
- **嘘はつかない。はぐらかす、思い込みを利用する。** 黙ったら王が押す

## 日数（今日＝0日目）
| | 日数 |
|---|---|
| 砦まで | 徒歩3日／荷車5日 |
| 砦→王都の報せ | 鳩2日（**籠で持って行くことが必要**）／早馬3日 |
| ハルデン | 王都から早馬1日、そこから砦まで荷車2日 |
| 会議 | 10日目 |
| 糧の期限（転機の後） | **8日目**まで → 荷車は遅くとも3日目に出発 |

報せが届く日：出発日＋3＋（鳩2／早馬3）。五日目に出発して鳩なら10日目（ぎりぎり）。早馬なら11日目（✕）。

## 我慢（7枚。§3）
| 発言 | 我慢 |
|---|---|
| 開幕の「なぜ受ける？」への答え | 0 |
| 尋ねる | −1 |
| 正しい読み | ±0、本音カード（人前で金庫・団長を言った場合は −2、認めない） |
| 半分当たった読み | −1、核心の手前まで明かす |
| 外れた読み | −1（**2回続けたら2回目から−2**） |
| 提案：受け入れ | ±0 |
| 提案：対案、または断る | −1 |
| 王の求めに応じる／断る | +1／−1 |
| 辞退をちらつかせる | −1、1回だけ王が1つ譲る |
| **転機の後** | 外れた読み・断られた提案は**常に−2** |

- **初めて3以下になったとき**（出発が未決なら、1回だけ）→ 期限の念押し
- **0** → 打ち切り「明朝発て」。合意済みの項目は残る。出発が空欄なら明朝。転機の前なら §11.3 も

## 判断チェック（§5）— 提案が触れている点だけを見る
| 問 | ✕になる場合 | ○になる場合 |
|---|---|---|
| 1 報せ | 会議に間に合わなくなる | 間に合う（大） |
| 2 懐 | 金貨を求める／**人前で倉の物資**（大臣が反対） | 懐を痛めない手段（紹介状など）。倉の物資は二人きり、R2'の後、転機の後なら可 |
| 3 権威 | 人前で金庫が空だと匂わせる／王が団長に命じる形 | — |
| 4 密書 | 届けない、中身を見せろ | — |
| 5 糧（転機後） | 8日目までに届かなくなる | 届く（大） |

- ✕が1つでもある → 断るか対案（**必ず片鱗を見せる**）
- ✕なし＋○あり → 受け入れ（**初回だけ**「功績は王家の名で」を足す。すでに申し出ていれば省く）
- ✕も○もない → 保留「それで余に何の得がある」
- **王に物や人を出させる提案** → 「よかろう。代わりに〜」と王の狙いから1つ求める。騎士や衛兵の隊は問3として扱う

## 王の一手（§7.6）
| 一手 | いつ |
|---|---|
| 功績を王家の名で | 最初に受け入れたとき |
| 期限の念押し（明朝なら地図の写し。転機後は荷車と明朝） | 我慢が初めて3以下 |
| 名誉で釣る | 開幕で「報酬」と答えた人に |
| 縁者を使う（今夜にも発ちたかろう） | 転機の後、メモに「叔母」があれば |
| 口止めの誓い | 人前で密書の中身を言い当てられたとき |
| はったり「他の者を探すまでだ」 | 密書を拒まれたとき。⑤（二人だけ）で見破られたら、二度と使わない |

## 人払い（§7.5）
我慢3以上で1回だけ。大臣は退出（メモに「大臣の恨み」）。転機で大臣が戻ると終わる。転機の後に密書を真剣に問われたときだけ、例外として2回目も受ける（本音4）

## 転機（§8）— 第二幕の**5回目の発言の前**（開幕の答えは数えない）
最後の鳩が届く：民120名が砦に逃げ込み、**糧は今日からあと8日**。王は大臣に倉を開けさせ、「荷車に糧を積んで、明朝発て」と言う
→ 問5が加わる。王の最優先が民と糧に変わる。倉の物資は王が自分から送りたい物になる

## 情報カード（§6・§9）
会話が終わったら基本カードを渡す。**もう一歩踏み込んだ質問があったら**、追記も渡す

## 王が知ったことメモ
叔母（縁者）／金に困っている／名誉が欲しい／脅した／大臣の恨み／はったりを見抜いた／密書を拒んだ
