# おかえりください勇者様（試作 v1）

`index.html` をデスクトップの Chrome で開くだけで遊べます（ビルド不要）。一日＝来客3人、10〜15分。
`index.html?fast` で演出が速くなります（確認用）。

## 遊び方
1. 🔍 客の体・持ち物・まわり（窓、門番）の札を調べる／💬 質問する → 🧠「本当の望み」と手がかりが増える
2. 💡 望みをひとつ選び、城でできること（証書・芝居・雇う・工兵・兵・薬師・魔王様に一目）と組み合わせて提案
3. 条件をつけられたら：城でできることを足す／条件をのむ／弱みを突く／取り下げる
4. 交渉しない道：👑 魔王様に通す（戦い・謁見）／🚪 お引き取り願う
5. 日の終わりに、魔王様の元気・評判・領地と「その後」の報告

## ファイル
| ファイル | 中身 |
|---|---|
| `game.js` | `VISITORS`（客ごとの手がかり・質問・反応・結末）と進行。客の追加・調整はここだけ |
| `art.js` | 絵（トト・魔王様・客・竜・背景） |
| `style.css` / `index.html` | 画面 |
