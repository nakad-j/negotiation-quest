# デジタル試作 v1「三日の勅命」

ブラウザで遊べる最初のデジタル試作です。目的は「交渉そのものが面白いか」を、実際に操作して確かめることです。

## 起動方法

`index.html` をブラウザ（Chrome 推奨）で開くだけです。インストールもサーバーも要りません。

```
open prototype/digital_v1/index.html
```

- 文章はクリックか Enter で進みます
- 交渉中、ログをクリックすると文章が早送りになります
- 開発用：`index.html?skip=neg` で探索を飛ばし、主な情報カードを持った状態で謁見の第二幕から始まります

## 遊びの流れ（1周 15〜20分）

1. **序・自宅**：叔母の便り、幼なじみリオの「紹介状」の話を聞く
2. **第一幕**：王が条件を言い渡す（三日で発て／銀貨二十枚／騎士は出せぬ／密書の中身は問うな）
3. **城の探索**：4か所のうち3か所を回る。どの質問を深掘りするかで、得られる話が変わる
4. **第二幕（交渉）**：王の我慢（ろうそく7本）が尽きる前に、旅の条件を勝ち取る
   - **尋ねる**：王に質問する（我慢−1）
   - **異を唱える**：王の言葉を1つ選び、手帳のカードを根拠に突く（または勘で言う）。筋が通れば王は本音を明かす。外れると我慢が減り、続けて外すと「当て推量はやめよ」と言われる
   - **提案する**：解放された条件を組み合わせて提案する。王は隠れた事情に照らして、受け入れる／対案を出す／断る（断るときは理由の片鱗を見せる）
   - **人払い**：大臣を下がらせると、王は本音を言いやすくなる
   - **辞退をちらつかせる**：一度だけ王が譲る。二度目は追い出される
   - 王は自分から求め（功績、期限の念押し、口止め）、こちらの弱み（叔母）を使い、はったりも言う
5. **転機**：交渉の途中で砦から最後の鳩が届き、状況が変わる
6. **結末**：条件どおりの旅の顛末、王の私記、結果のまとめ

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 入口 |
| `engine.js` | 交渉のルールと結末の計算（DOM 非依存。Node でも動く） |
| `story.js` | 導入・探索の文章 |
| `ui.js` | 画面とインタラクション |
| `style.css` | 見た目 |
| `tests/sim.js` | 代表的な7ルートの通しテスト：`node tests/sim.js`（`-v` で会話ログも表示） |

技術：素の HTML／CSS／JavaScript。ビルドも依存ライブラリもなし。
設計の参考：`prototype/paper_v1/`（紙プロトタイプ）。

## 主な数値（engine.js で調整）

- 王の我慢 7、転機は第二幕の4回目の行動の後
- 今日を0日目として、会議は10日目、砦の糧は8日目まで
- 徒歩3日、荷車5日、鳩2日、早馬3日
- 準備・物資・仲間が足りないと、道中で1〜2日遅れる
