# リーナとの交渉・デジタル試作 v1

ブラウザ（Chrome推奨・デスクトップ）でファイルを開くだけで遊べます。ビルド・ライブラリ不要。

1. **`tutorial.html` — はじめての交渉（現在の主な試作）** 2〜4分。結末5種類。
   一行が城に着いた夜。「今夜、魔王のところへ通して」の裏にある事情を、観察で見つける。
2. `index.html` — 旧・本編の試作（7結末）。**方針変更により保守対象外**。

### 操作の色分け（tutorial）
🔍 調べる＝水色の札 ／ 🎁 差し出す＝緑のカード（選ぶ→確認→卓に置く／やめる・Esc）／ 💬 答える＝黄の枠 ／ 📖 手帳＝琥珀の札

### チュートリアルで分けたもの
`tutorial.html` / `tutorial.js` / `tutorial.css` はチュートリアル専用。本編側の変更は `index.html` 上部のリンク1つだけ。
`art.js` と `style.css` は共有（変更なし）。

### 本編

- 1回のプレイ：3〜6分。結末は7種類（結果画面に「見た結末 n/7」）。
- `index.html?fast` で演出が速くなります（確認用）。
