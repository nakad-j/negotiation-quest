# おかえりください勇者様 試作 v2（勇者レオンのみ）

`index.html` をデスクトップの Chrome で開くだけで遊べます（ビルド不要）。1回 5〜8分。
`index.html?fast` で演出が速くなります（確認用）。設計は `docs/redesign/05_おかえりください勇者様_交渉の再設計.md`。

## 遊び方
- トトの返事を3つの中から選ぶ
- レオンの吹き出しの **色つきの言葉** をクリック → その言葉を聞き返す
- **……（黙って待つ）**
- 🔍 レオンの姿・持ち物を見る → 話のきっかけが増える
- 話をやめるなら：👑 魔王様に通す ／ 🚪 お引き取り願う
