# おかえりください勇者様 試作 v2（勇者レオンのみ）

`index.html` をデスクトップの Chrome で開くだけで遊べます（ビルド不要）。1回 5〜8分。
`index.html?fast` で演出が速くなります（確認用）。設計は `docs/redesign/05_おかえりください勇者様_交渉の再設計.md`。

## はじまりの流れ
1. 魔王様が、トトに仕事（交渉係）を言いつける
2. 最初のお客さま：勇者レオンが城に来て、トトと短くあいさつする（まだ選ぶことはない）
3. 観察の画面：レオンの全身の絵の上で、手・剣・鎧の札・胸元の手紙を、直接押して調べる
4. 「話す」→ レオンの第一声から、交渉がはじまる（話のとちゅうでも「🔍 レオンを、よく見る」で観察にもどれる）

## はじめての手引き
初めて開くと、観察の画面が開いたところで、1手ずつの手引きが出ます。
お知らせを読んで **OK** → 光っているものだけが押せる → やってみる → 次のお知らせ、のくり返しです（お知らせが出ているあいだは、OK しか押せません）。
1. 🔍 レオンの「手」を調べる → 2. 「話す」（ほかの場所も自由に調べられる）→ 3. 吹き出しの言葉「一騎打ち」を聞き返す → 4. 返事を3つから1つ選ぶ → 「これで準備は整いました」の OK で、すべての操作が使えるようになります。

- 終えるとブラウザに記録され、次から（「もう一度」を含む）は出ません。もう一度見るときは `index.html?tutorial`。
- 手引きで行う3手は、ふつうの遊びと同じ処理です（ルール・せりふは変えていません）。

## 遊び方
- トトの返事を3つの中から選ぶ
- レオンの吹き出しの **色つきの言葉** をクリック → その言葉を聞き返す
- **……（黙って待つ）**
- 🔍 レオンの体・持ち物を、観察の画面で直接押して調べる → 話のきっかけが増える
- 話をやめるなら：👑 魔王様に通す ／ 🚪 お引き取り願う

## ファイル
| ファイル | 中身 |
|---|---|
| `game.js` | `WORDS`（聞き返し）・`OPTIONS`（トトの返事）・`silence`・`summaryReact`・`OUTCOMES`。せりふの調整はここ |
| `v2.css` | v2 の画面（v1 の `style.css` に重ねる） |

| `storybook.js` / `storybook.css` | 絵本の見た目。導入・観察・応対・結末を、キービジュアルの絵（背景・アーチの額の人物・顔絵）と羊皮紙の枠で描く。人物・表情・背景の対応は `storybook.js` の `CHARS` / `BG`（新しい訪問者は `CHARS` に1つ足す）。観察の画面は `CHARS.<人>.observe`（全身の絵と、調べる場所の当たり判定。絵に対する割合 0〜1 なので、絵の大きさが変わってもずれない）。`storybook.js` を外すと、`art.js` の仮の絵と🔍札に戻る |
| `assets/` | `picture/keyvisual/` の設定画から切り抜いた絵（背景・人物・表情）と、`picture/fullbody/` の全身の絵（黒い地を透過にしたもの：`chara/leon_full.webp`）。作り直すときは `assets/crop_keyvisual.py`（要 Pillow）。設定画の切り抜きは仮の素材で、透過の立ち絵ではない |
